# Ibis — 배포 저장소

**Ibis**는 아래아한글(HWP)·MS Word용 서지·인용 관리 도구입니다(EndNote식 CWYW).
이 저장소는 **베타 배포 전용**입니다 — 소스 코드는 비공개 저장소에서 관리됩니다.

## 다운로드
[Releases](../../releases)에서 최신 `Ibis-<버전>-win64.zip`을 받아 압축을 풀고 `Ibis.exe`를 실행하세요. 설치가 필요 없습니다.

## 요구 사항
- Windows 10/11 (64비트)
- 한글 2022/2024 설치(한글 연동 시) · MS Word(선택)

## 주요 기능
- 한글/Word 문서에 인용 삽입(누름틀/콘텐츠 컨트롤) + 참고문헌 자동 생성·갱신
- KCI · ScienceON · Crossref · OpenAlex · Semantic Scholar · arXiv 검색, DOI 즉시 서지화
- 서지 그룹(프로젝트/하위) · 태그 · 첨부(PDF) · 중복 정리 · BibTeX/RIS/CSL-JSON 가져오기·내보내기
- 학회별 인용 스타일 편집기(강조 매트릭스·프리셋 공유), 도서관 교외접속 경유
- 문서명 변경·다른 PC 이어작업에 강건한 문서 추적(UUID)

## 베타 안내
- 처음 실행 시 Windows SmartScreen 경고가 뜰 수 있습니다("추가 정보" → "실행").
- 한글 연동 중 보안 모듈 팝업이 나타날 수 있습니다.
- 문제 제보는 이 저장소의 Issues에 남겨주세요.
