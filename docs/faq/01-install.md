# 시작하기 · 설치 · 환경

[자주 묻는 질문 목차](../FAQ.md)

## Ibis 는 다른 서지 관리 도구와 뭐가 다른가요?

- **국내 학술 DB 를 앱 안에서 직접 검색합니다** — KCI·ScienceON·국립중앙도서관을 내보내기 파일 없이 바로 검색하고, 국문/영문 병기도 보강합니다.
- **원문 확보까지 앱 안에서** — 무료 공개(OA) 경로를 차례로 시도해 자동 확보하고, 구독 DB 는 도서관 교외접속으로 연결하며, 학위논문은 RISS→dCollection 경로를 자동으로 따라갑니다.
- **읽고 분석하는 것까지** — 인앱 PDF 뷰어·주석, AI 리서치 노트·비판적 검토, 태그 그래프 뷰.
- **아래아한글(HWP) 본문 인용** — 여러 기능 중 하나입니다. 한글이나 Word 를 쓰지 않아도 나머지는 그대로 씁니다.
- 데이터는 **로컬 우선**이고 CSL-JSON 으로 열려 있어 특정 DB 에 묶이지 않습니다.

## 설치본(setup.exe)과 zip 중 뭘 받나요?

- **setup.exe** (권장) — 관리자 권한 불필요, 시작 메뉴·바탕화면 아이콘, 제어판에서 제거.
- `win64.zip` 은 앱이 업데이트할 때 내려받는 파일입니다. 직접 받아 풀면 자동 업데이트·바로가기·제거가 되지 않습니다.

## 지난 버전을 받고 싶은데 릴리스에 최신 하나만 보여요.

- 지난 버전은 내려받을 수 없습니다. 릴리스 페이지에는 최신 판만 보입니다.
- 이미 설치해 쓰고 계신 판은 그대로 돌아갑니다. 판올림도 앱 안에서 하던 대로 됩니다.
- 새 판에 문제가 있어 되돌려야 한다면 [이슈](https://github.com/dodaseo/ibis-releases/issues)로 알려 주세요 — 지난 판을 다시 열어 드립니다.

## 설치할 때 'Windows의 PC 보호'(SmartScreen) 경고가 떠요.

- 코드 서명 인증서가 없어서 나는 경고입니다.
- `추가 정보 → 실행` 으로 진행.
- 걱정되면 릴리스의 `.sha256` 과 대조: `Get-FileHash <파일> -Algorithm SHA256`.

## 어디에 설치되나요? 관리자 권한이 필요한가요?

- 관리자 권한 없이 `%LOCALAPPDATA%\Programs\Ibis` 에 설치됩니다. 설치 위치는 묻지 않습니다 — `C:\Program Files` 에 설치하면 인앱 업데이트가 폴더를 교체하지 못하기 때문입니다.
- **서재(서지·첨부)는 설치 폴더 밖**에 있어 제거·재설치·업데이트로 지워지지 않습니다 — 아래 '어디에 저장되나요' 참고.

## 창의 ×를 눌렀는데 앱이 꺼지지 않아요.

- **− 버튼**은 작업표시줄로 최소화하고, **본창의 × 또는 Alt+F4**는 창을 숨긴 뒤 **시스템 트레이에서 계속 실행**합니다. PDF 본문 색인·서재 동기화 등 진행 중인 작업도 계속됩니다.
- 다시 열려면 작업표시줄 오른쪽 **Ibis 트레이 아이콘을 두 번 클릭**하거나, 오른쪽 클릭 메뉴에서 **Ibis 열기**를 선택하세요. 아이콘이 보이지 않으면 숨겨진 아이콘 목록(⌃)을 확인하세요.
- 완전히 끄려면 **파일 › 종료** 또는 **트레이 메뉴 › 종료**를 선택합니다. 업데이트 설치와 Windows 종료·로그오프 때도 앱을 완전히 종료합니다.
- 설정·PDF·상세 같은 별도 창의 ×는 그 창만 닫습니다.

## 서지 정보나 태그를 고쳤는데 화면이 그대로예요.

- 서재가 바뀌면 **클릭하지 않아도** 목록·상세·사이드바 건수가 갱신됩니다. 검색 결과를 담은 뒤 뒤에서 채워지는 서지 정보, PDF 창에서 돌린 AI 요약, 다른 창에서 한 편집도 본창에 바로 보입니다.
- 입력 중이면 상세를 다시 그리지 않습니다 — 손을 뗀 뒤 반영됩니다. 검색·질문 결과 화면은 그대로 둡니다.

## 설치 마지막 화면의 'AI 연동 설정 열기' 는 뭔가요?

- 켜면(기본 꺼짐) 설치 후 첫 실행에서 AI 설정 화면이 먼저 열립니다. 켜지 않아도 나중에 ⚙설정에서 할 수 있습니다.
- 인스톨러가 **AI CLI 를 대신 깔지는 않습니다** — 로그인이 브라우저 인증이라 무인 설치로 끝나지 않기 때문입니다.

## 버전 번호가 네 자리가 된 이유는 무엇인가요?

- `2026.9.20.0`(2026-09-28)부터 **연.월.큰 변경.작은 수정**으로 구분합니다. 작은 수정은 `2026.9.20.1`, 다음 큰 변경은 `2026.9.21.0`처럼 올립니다.
- 예전 세 자리 버전도 그대로 인식하므로 사용자가 번호를 바꿀 필요는 없습니다.

## Mac·리눅스에서도 되나요?

- 현재는 **Windows 전용**입니다.
- 한글 자동화가 Windows COM(`HWPFrame.HwpObject`) 전용이라 macOS 에서는 **본문 인용 삽입만** 불가능합니다.
- 검색·원문 확보·PDF 뷰어·AI·그래프·서지 관리는 기술적으로 이식 가능해, macOS 판은 검토 중입니다(수요 확인 후).

## 처음 켜니 'Ibis 시작하기' 창이 떴어요. 다 입력해야 하나요?

- 전부 **선택**입니다. [나중에]로 건너뛰어도 됩니다.
- 안내 항목: ①서재 위치 ②무료 원문 조회용 이메일 ③AI 제공자.
- 학술 DB 항목은 없습니다 — KCI·국립중앙도서관은 설정 없이 바로 검색됩니다.
- 검색·인용 삽입·서지 관리는 설정 없이 됩니다. 건너뛴 항목은 ⚙설정에서 언제든.

## API 키 없이 쓸 수 있나요?

- 됩니다. 검색·인용 삽입·서지 관리 모두 키 불필요.
- 국내 학술 DB와 법·정책 DB는 내장 키로, 해외 DB는 무키 또는 기본 키로 사용합니다. 별도 키 등록은 필요하지 않습니다.
- 이메일·Google Books·Semantic Scholar·OpenAlex 개인 키는 선택 사항입니다. OpenAlex·S2의 기본 키 한도는 사용자들이 공유하며, 개인 키를 등록하면 그 키를 우선합니다.

## 데이터와 API 키는 어디에 저장되나요? 클라우드에 올라가나요?

**두 자리로 나뉩니다.**

- **서재(서지·첨부)** — 새로 설치하면 `문서\Ibis` 에 생깁니다.
  - 기존 사용자의 서재는 옮기지 않고 예전 위치(`%LOCALAPPDATA%\Ibis`)를 그대로 씁니다. 내 서재가 어디인지는 `⚙설정 › 서재` 에서 확인하고, 옮기려면 거기 [폴더 변경]을 씁니다.
  - 담기는 것: `library.json` 서지 · `attachments\` 첨부 PDF · `docstore\` 문서별 인용 · `journal_styles\` 저널 스타일.
- **이 PC 전용** — `%LOCALAPPDATA%\Ibis` 에 `secrets.json`(API 키·AI 설정·테마)과 검색 색인(`.db`).
  - **`secrets.json` 은 항상 로컬 전용** — 어떤 동기화에도 실리지 않습니다. 그래서 PC 마다 따로 넣습니다.
- 서재만 클라우드 폴더로 옮길 수 있고, 이때 서지·첨부·docstore·저널 스타일이 함께 이동합니다(계정 기반 동기화는 '내 서재 동기화' 를 보세요).

## `library.json` 과 SQLite(`.db`) 중 진짜 데이터는?

- `library.json` 이 원본이고 클라우드 동기화 대상입니다.
- `.db` 는 검색 색인용 로컬 프로젝션 — 지워도 `library.json` 에서 재생성됩니다.
- 문제 시 환경변수 `IBIS_BACKEND=file` 로 파일 백엔드 복귀(옛 이름 `HWPENDNOTE_BACKEND` 도 그대로 인정됩니다. 서재 위치는 `IBIS_LIBRARY` / 옛 `HWPENDNOTE_LIBRARY`).
