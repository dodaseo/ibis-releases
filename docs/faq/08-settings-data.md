# 화면 · 설정 · 데이터

[자주 묻는 질문 목차](../FAQ.md)

## 컬렉션 숨김·색·이름을 바꿔도 바로 반영되지 않아요.

- 2026.9.6 에서 고쳤습니다. 숨김·표시·색·이름 변경·최상위로 이동·컬렉션에 담기·즐겨찾기가 누르는 즉시 화면에 반영되고, 저장과 재조회는 뒤에서 이어집니다.

## 'PDF 본문 색인 중…' 이 자주 뜨고 오래 걸려요.

- 2026.9.19 에서 색인 엔진을 바꿔 **15배** 빨라졌습니다(서재 802편 실측 43분 → 3.4분). 새로 설치하거나 서재를 다른 PC 에서 열 때 체감이 큽니다.
- 이미 색인된 파일을 다시 읽지는 않습니다. 진행 표시는 **"k/할 것(새로 바뀐 것만)"** 입니다 — 종전에는 새 파일 둘만 색인해도 전체를 다시 도는 것처럼 보였습니다.
- 색인은 PC 마다 따로 만듭니다(`%LOCALAPPDATA%\Ibis\index`). 서재 동기화나 폴더 동기화로 옮기지 않습니다 — 첨부 PDF 에서 다시 만드는 쪽이 빠르고 작습니다.

## 창을 끌면 마우스를 늦게 따라와요.

- 2026.9.6 에서 고쳤습니다. 창 끌기를 Windows 에 맡겨 Aero 스냅도 됩니다.
- 첫 PDF 본문 색인이 도는 동안은 여전히 조금 느릴 수 있습니다. 상태줄의 `n/전체` 가 끝나면 풀립니다.

## 상세 패널의 버튼이 흐리게 눌리지 않습니다.

- 그 문헌에서 실행할 수 없는 기능이라 비활성화한 것입니다. 마우스를 올리면 이유와 대안이 표시됩니다.
- 자주 보는 경우 — AI 리서치 노트·비판적 검토는 **첨부 PDF 가 있어야** 합니다(초록만으로는 안 됩니다) · 서지정보 AI 채우기는 DOI 나 PDF 가 있어야 합니다(DOI 가 있거나 학위논문이면 AI 설정과 무관하게 켜집니다 — 그 경로는 KCI·Crossref 로 채웁니다) · 원문 확보는 이미 PDF 가 붙었거나 웹·신문기사면 꺼집니다 · 서재에 담기 전 검색 결과와 휴지통 문헌은 잠깁니다.
- 행 우클릭 메뉴도 같은 판정을 씁니다.

## 법령·판례의 원문 PDF 도 받아지나요?

- **법령은 됩니다** — [원문 확보]가 법제처에서 **전문 PDF** 를 받아 첨부합니다(초·중등교육법이면 31쪽). 로그인도 키도 필요 없습니다.
- 판례는 앱이 대신 받지 못합니다(저장 화면이 로그인 세션 안에서만 동작합니다). 대신 [원문 페이지 열기] 가 켜지고, 그 화면의 [저장]으로 직접 받으면 됩니다.
- **정책자료·법률안·회의록**(국회도서관)은 [다운로드]가 로그인을 요구해 앱이 대신 받지 않습니다. 직접 받은 PDF 를 **첨부(＋)** 로 넣으면 됩니다.

## 크레딧이 다 떨어졌는데 다음 날에도 채워지지 않아요.

- 처음 받는 **체험 크레딧 100** 은 **한 번만** 주는 것이라 다 쓰면 채워지지 않습니다.
- ⚙설정 › AI 의 **[베타 무료 구독]** 을 시작하면 그 자리에서 **하루 50크레딧**이 매일 채워집니다. 승인 대기가 없고, **결제 수단도 받지 않습니다.**
- 판올림 뒤에 계정이 체험으로 옮겨진 경우도 같습니다 — 안내가 한 번 뜨고, 구독을 시작하면 다시 하루 50입니다. 다만 이것은 **구독한 적 없는 계정**만입니다: **이미 무료 구독을 시작하셨다면 판올림해도 그대로 하루 50크레딧**이고 안내도 뜨지 않습니다.

## 계정을 바꿨는데 플랜·크레딧이 예전 계정 것으로 보여요.

- 2026.9.14 에서 고쳤습니다. 계정을 바꾸면 즉시 다시 읽습니다.
- 서버가 일시적으로 혼잡한 것을 '로그인 끊김'으로 표시하지 않습니다. 잠시 뒤 자동으로 다시 시도하고, 실제로 만료된 때만 안내합니다.

## 테마는 몇 가지인가요?

- **16종** — 자체 제작 4종(Slate·Ivory·Bright·Graphite) + 다크 8종(Dark Modern·One Dark Pro·Dracula·Nord·Monokai·Tokyo Night·Solarized Dark·GitHub Dark) + 라이트 4종(Solarized Light·GitHub Light·Quiet Light·Ayu Light).
- 기본값은 **Ivory**(종이톤) 입니다. **그전부터 쓰시던 분의 테마는 그대로 유지**되고, 새로 설치했거나 테마를 한 번도 바꾸지 않은 경우에만 적용됩니다.
- ⚙설정 › 일반 › 표시 › 테마에서 선택 — 즉시 적용, 저장되어 재시작 후에도 유지.
- 자체 제작 4종은 타이틀바·레일이 다크 고정, 나머지는 **크롬까지 테마 색**을 따릅니다.

## 글꼴을 바꿀 수 있나요?

- 화면 글꼴은 Pretendard 하나입니다. 글꼴 선택과 내려받기(본명조·나눔·JetBrains Mono)는 뺐습니다.
- Pretendard 를 못 쓰는 환경에서는 맑은 고딕으로 대체됩니다. 예전에 받아 둔 글꼴 파일(`%LOCALAPPDATA%\Ibis\fonts`)은 더 쓰이지 않으니 지워도 됩니다.

## 왼쪽 레일 아이콘을 다시 누르면?

- 그 패널이 **접히고/펴집니다** — 목록을 넓게 볼 때 사용(그래프 모드에서는 그래프 패널).

## 설정한 키를 지우려는데 칸을 비워도 안 지워져요.

- 키 칸은 '빈 칸은 유지' 규칙입니다.
- 설정된 키 옆의 **'지움' 버튼 → 저장** 으로 삭제. 지워도 검색은 그대로입니다 — 남은 칸은 전부 선택입니다.
- 환경변수로 넣은 키는 UI 에서 지워지지 않습니다.
- 이메일 칸은 예외 — 비우고 저장하면 삭제됩니다.
- KCI·국립중앙도서관은 입력 칸이 없어 지울 것도 없습니다. `secrets.json` 에 예전에 넣어 둔 `kci_api_key`·`nl_seoji_key` 는 **이제 쓰이지 않으니** 그대로 두어도 무해합니다.

## '이메일(OA·polite)' 칸은 무슨 키인가요?

- 발급 키가 아니라 **Unpaywall 조회 + Crossref polite pool 등록용 이메일**.
- 필수는 아니지만 OA 자동 확보 품질을 위해 권장.

## 도구에 있던 '서재' 가 안 보여요.

- **`⚙설정 › 서재` 탭으로 옮겨졌습니다** — 서재 위치 변경·새로 만들기·열기·사본 저장(백업)·업데이트 확인이 거기 있습니다.
- 설정은 이제 **일반 · AI · 검색·원문 · 클라우드 · 서재** 5개 탭입니다(레일 맨 아래 ⚙).
- **도구 패널은 없앴습니다** — 가져오기·내보내기·컬렉션 공유는 `파일` 메뉴, 일괄 정리(중복 문헌 정리 · 원문 일괄 확보 · AI 태그 정리 · 첨부 이름 일괄 정리)는 `서재` 메뉴로 갔습니다.

## 검색 결과에 색칠이 됐는데 뭔가요?

- 제목·저자·수록처에서 검색어와 일치하는 부분을 표시해 어느 부분이 일치했는지 보여 줍니다.
- 세 칸 어디에도 검색어가 없으면 `일치: 초록·주제어` 처럼 일치한 칸을 표시합니다.
- 검색 결과 화면에서만 표시합니다.

## '항상 위 고정' 이 재시작하면 풀려요.

- 정상 — 이 설정은 저장하지 않습니다. 필요할 때 다시 체크하세요.
- 본창에만 적용(설정·그래프·상세·PDF 등 별도 창은 제외).

## 별도 창에서 '닫기' 를 누르면 앱 전체가 꺼지나요?

- 아니요 — 창 컨트롤은 **지금 조작 중인 창에만** 적용됩니다.
- 앱 전체를 끄려면 **파일 › 종료** 또는 **트레이 메뉴 › 종료**를 선택합니다. 본창의 ×는 트레이로 숨깁니다.

## 설정·PDF 같은 별도 창이 화면 밖이나 엉뚱한 모니터에 떠요.

- 고쳤습니다(125·150% 배율에서 창 좌표 계산 오류). 최신 버전으로 업데이트하면 본창 옆에 뜹니다.

## 업데이트했더니 컬럼 폭이 초기화됐어요.

- 업데이트 시 WebView 캐시를 비우면서 사소한 로컬 상태가 초기화될 수 있습니다.
- 서지·PDF 등 실제 데이터에는 영향 없습니다.
- 헤더 경계를 다시 드래그하면 저장되고, 더블클릭하면 기본 폭으로 복원.

## 앱을 영어로 쓸 수 있나요?

- 현재 웹판 UI 는 **한국어 전용**입니다.
- 서지 편집의 '언어' 항목은 참고문헌의 국문/영문 표기용이며 인터페이스 언어와 다릅니다.

## 온보딩을 건너뛰었어요.

- 모든 항목(서재 위치·이메일·도서관 경유·AI)은 ⚙설정에서 언제든 변경 가능.
- 이미 데이터가 있으면 온보딩 창은 다시 뜨지 않습니다.

## 버전·라이선스·저작권은 어디서 확인하나요?

- `도움말 › Ibis 정보 · 라이선스` — 제품명·버전·저작권·배포 라이선스·실행 환경 + **제3자 구성요소 고지**.
- Ibis 는 **개인·학술·연구·교육 목적 무료**이며 재배포·판매·역공학은 허용되지 않습니다.
- **Ibis 로 만든 서지 데이터와 문서는 전적으로 사용자의 것입니다.**


## 인터넷이 없어도 사용할 수 있나요?


이 PC에 저장된 서지의 조회·편집, 서재 내 키워드 검색, PDF 열기·주석, 인용과 참고문헌 서식 작업은 계속할 수 있습니다. 외부 DB 검색·원문 다운로드·클라우드 AI·동기화·업데이트에는 연결이 필요합니다. 로컬 AI는 모델과 로컬 서버가 준비돼 있어야 합니다.

연결 단절이 감지되면 상태줄에 **오프라인 · 로컬 작업 가능**이 표시됩니다. 동기화가 실패하면 **동기화 대기 · 재시도**를 눌러 다시 시도할 수 있습니다. 연결이 돌아오면 동기화만 자동 재개하며, AI 작업은 다시 실행해야 합니다.

OneDrive의 온라인 전용 파일이나 네트워크 드라이브에 있는 PDF는 미리 이 PC에 내려받아 두세요. 네트워크에 연결돼 있어도 특정 서버에 접근하지 못할 수 있으므로, 오프라인 표시가 없다는 것이 모든 온라인 기능의 정상 작동을 뜻하지는 않습니다.
