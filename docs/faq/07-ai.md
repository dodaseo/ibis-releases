# AI 기능

[자주 묻는 질문 목차](../FAQ.md)

## 로컬 AI는 어떻게 연결하나요?

- Ollama 또는 LM Studio에서 텍스트 생성 모델과 서버를 먼저 준비한 뒤 `⚙설정 › AI`의 1차 또는 폴백으로 **로컬 AI (Ollama·LM Studio)**를 고릅니다.
- **로컬 서버 연결 → 연결 확인 → 모델 조회** 순서로 연결하고 모델을 반드시 지정하세요. 모델명을 직접 입력할 수도 있습니다. Ibis가 모델을 내려받거나 서버를 실행하지는 않습니다.
- **본문 상한 (자)**는 기본 4,000자입니다. 모델의 문맥 길이를 바꾸는 설정은 아니며, 연결이 되더라도 답변과 쪽 근거는 원문과 확인해야 합니다.
- 서버가 클라우드 모델을 쓰거나 외부 제공자를 폴백으로 지정하면 본문이 외부로 전송될 수 있습니다([개인정보 처리방침](../PRIVACY.md#ai-제공자와-로컬-서버)).

## AI 를 쓰려면 따로 돈을 내야 하나요?

- AI는 다음 방식 중 하나를 골라 씁니다.
- **Ibis AI**(키·CLI 불필요): 구글 로그인만 하면 크레딧으로 씁니다. 시작하면 체험 크레딧 100(다 쓰면 채워지지 않습니다), [베타 무료 구독] 을 시작하면 하루 50크레딧이 매일 채워집니다(한국시간 오전 9시). 베타 기간에는 요금이 없고 결제 수단도 받지 않습니다. 정식 요금이 정해지면 구독자에게 먼저 알리고, 그때 계속할지 선택합니다.
- **CLI형**(키 불필요): `Claude CLI (구독)` · `Antigravity CLI (Google 구독)` · **Codex CLI (ChatGPT 계정)** — 설치 + 최초 1회 로그인. Codex를 이용할 수 있는 ChatGPT 계정이 필요하며 설정에서 설치·로그인·상태 확인·업데이트를 진행합니다.
- **API형**(본인 키): `Anthropic API 키` · `OpenAI API 키` · `Gemini API 키`.
- **로컬 AI**: Ollama·LM Studio 등 사용자가 실행한 서버의 모델을 연결합니다. 해당 서버·모델의 이용 조건이 적용됩니다.
- 외부 CLI·API는 해당 계정의 사용량 한도와 요금이 적용됩니다. 로컬 AI도 연결한 서버·모델의 이용 조건을 확인하세요.
- AI 를 설정하지 않아도 나머지 기능은 그대로 됩니다.

## Ibis AI 크레딧은 얼마나 드나요? 모르고 다 써 버리지 않나요?

- **글자 수(토큰) 기준 종량제**입니다 — 짧은 질문은 적게, 수백 쪽 학위논문 요약은 많이 듭니다.
- 실행 전에 예상 크레딧을 보여 주고 동의를 받습니다. 남은 크레딧으로 모자라면 그 자리에서 알립니다.

## 여럿이 같이 쓰면 'AI 제공자 오류(429)' 가 납니다.

- 오류 대신 기다립니다. 서버에 여유가 생길 때까지 최대 90초 동안 재시도하고, 그동안 상태줄에 표시됩니다.
- 끝내 처리되지 않으면 그 사실을 알리고, 폴백 제공자가 있으면 그쪽으로 넘어갑니다.
- ⚙설정 › AI 의 '동시 실행'은 Ibis AI 에서 2건까지만 적용됩니다. 한 사람이 서버 용량을 독점하지 않도록 한 제한입니다.

## CLI 제공자는 어떻게 설치·로그인하나요?

- ⚙설정 › AI 의 '설치' 버튼 → **1 설치 → 2 로그인 → 3 확인** 3단계 안내.
- 설치·로그인은 **별도 콘솔 창**에서 진행됩니다(설치 로그를 봐야 하고, 로그인은 브라우저 인증이 콘솔에서 끝나야 하므로).
- 각 벤더의 **공식 설치 방법**을 사용 — Claude Code 는 Node.js 없이 설치되는 네이티브 설치.
- 설치 후 **앱을 재시작할 필요가 없습니다**(Windows PATH 변경을 앱이 다시 확인).
- ⚠ Ibis 가 '항상 위 고정' 이면 콘솔 창이 뒤에 열릴 수 있습니다 — 작업표시줄을 확인하세요.

## 뷰어에서 어떤 PDF 는 글자가 안 보여요(테두리만 그려져요).

- 2026.9.15 에서 고쳤습니다. 뷰어가 그리지 못하는 글꼴 조합이 원인이며, 이제 글자가 빠진 쪽을 감지해 그 쪽만 Windows 내장 PDF 엔진으로 다시 그립니다. 따로 설치할 것은 없습니다.
- 글자 선택·본문 찾기·주석은 그대로 됩니다.

## 요약이나 PDF 대화가 엉뚱한 내용을 말해요.

- 화면은 정상인데 추출되는 글자가 어긋나는 PDF 가 있습니다(`Korean Journal of Sociology` 가 `,PSFBO+PVSOBM` 처럼). 오류 표시가 없어 알아채기 어렵습니다.
- 되돌릴 수 있는 것은 되돌리고, 되돌릴 수 없는 쪽은 그 쪽만 글자 인식으로 다시 읽습니다. 정상인 문서는 바뀌지 않습니다.
- 그래도 이상하면 스캔본일 수 있습니다 — 아래 항목을 보세요.

## 스캔본(이미지) PDF 도 요약되나요?

- 네. 글자가 없는 PDF 는 Windows 내장 글자 인식으로 본문을 뽑아 요약에 넘깁니다. 따로 설치할 것은 없고 자동으로 실행됩니다.
- 처음 한 번은 시간이 걸립니다(수십 쪽이면 십수 초~수 분).
- **시작하기 전에 먼저 알립니다** — 「스캔본입니다 — 글자를 먼저 읽습니다(42쪽). 긴 문서는 몇 분 걸릴 수 있습니다」. 서지 채우기는 앞뒤 몇 쪽만 읽으므로 그렇게 적힙니다. 그 뒤로는 **「… 텍스트 인식 3/42쪽」** 으로 진행이 보입니다.
- 한 번 읽은 PDF 는 결과를 PDF 옆에 저장해 다음부터 바로 처리되며, 그때는 안내가 뜨지 않습니다.
- 글자 인식은 AI 기능이 본문을 필요로 할 때만 실행됩니다(요약·비판적 검토·PDF 대화·서지 채우기). 뷰어로 여는 것만으로는 실행되지 않고, 배경 본문 색인도 글자 인식은 하지 않습니다.
- 글자 인식은 원본 그대로의 정확도가 아니므로, 요약이 엉뚱하면 OCR 처리된 PDF 로 교체해 보세요.

## AI 요약이 논문 앞부분만 읽는 것 같아요.

- 고쳤습니다. 학위논문 46편 기준으로 읽는 분량이 평균 59%에서 99%로 올랐습니다.
- 100쪽 넘는 논문의 결론·논의도 읽습니다. 얼마나 읽었는지는 결과에 적힙니다.

## AI 요약을 다시 돌리면 내 메모·태그가 지워지나요?

- 아닙니다 — 노트는 `## AI 요약` 섹션만 교체하고 **앞의 사용자 메모는 보존**.
- 태그·키워드도 직전 AI 가 넣은 것만 교체하고 수동 입력분은 유지.

## 서지정보 채우기는 항상 AI 를 쓰나요?

- 아닙니다. DOI 가 있으면 Crossref·KCI 를 먼저 조회합니다.
- 빈 항목이 남을 때만 첨부 PDF 표지를 AI 로 분석.
- DOI 만으로 다 채워지면 결과에 'AI 생략' 표시(사용량 절약).

## PDF 없이도 서지정보를 채울 수 있나요?

- DOI 가 있으면 PDF 없이 Crossref 로 채웁니다.
- DOI·PDF 가 **둘 다 없으면** 채울 수 없고 원문 확보를 먼저 안내합니다.
- 학위논문·단행본도 유형에 맞춰(수여기관·학위 / 출판사·출판지) 채워집니다.

## AI 가 429(사용량 제한) 오류를 냅니다.

- 사용량·속도 제한입니다. 잠시 후 재시도하거나 다른 제공자·모델로 변경.
- ⚙설정에서 **'폴백' 제공자**를 지정하면 1차 실패 시 자동 재시도합니다.

## 모델 칸은 비워도 되나요?

- 비우면 CLI형은 개인 기본값, API형은 내장 기본값(Anthropic `claude-haiku-4-5` · OpenAI `gpt-4o-mini` · Gemini `gemini-2.0-flash`).
- 모델명을 넣으면 호출마다 그 모델을 강제(haiku 계열은 빠르고 절약적).

## 여러 문헌을 한 번에 요약·채우기 할 수 있나요?

- 다중 선택 후 우클릭 › 'AI 요약 (N건)' · '서지정보 채우기 (N건)'.
- 일괄 요약은 동시에 처리합니다. `⚙설정 › AI` 의 [동시 실행](1~5, 기본 3)만큼 나란히 처리합니다.
- 값을 올려도 항상 빨라지지는 않습니다. 구독(CLI)은 사용량 한도에 더 빨리 닿고, API 키는 분당 한도에 걸립니다. 한도로 보이는 실패가 두 건 이상이면 결과 요약에서 낮추라고 안내합니다.
- ⚠ 이 설정은 **AI 호출에만** 걸립니다 — 학술DB 검색·원문 확보의 동시 요청 수는 따라 올라가지 않습니다.
- 진행률·예상 남은 시간이 표시되고, 완료 후 건별 성공/실패·태그를 브리핑으로 확인.
