# 원문(PDF) 확보 · 뷰어

[자주 묻는 질문 목차](../FAQ.md)

## 원문이 자동으로 안 받아져요.

- 무료 공개(OA) 경로에 없거나 구독 DB 전용인 경우입니다.
- 자동 확보 순서: arXiv → Unpaywall → Semantic Scholar → 랜딩 메타(`citation_pdf_url`) → KCI 무료원문.
- ⚙설정에 **이메일을 넣으면 Unpaywall 이 켜져** 확보율이 오릅니다.

## 구독 DB(DBpia·KISS 등) 원문을 자동으로 받아주나요?

- **아니요** — 약관·기관 정책상 자동 로그인·클릭·다운로드는 하지 않습니다(준법).
- 앱은 도서관 교외접속 경유로 **원문 페이지를 브라우저에 열어주기만** 합니다.
- 직접 받은 PDF 는 다운로드 폴더 감시로 자동 첨부됩니다.

## 도서관 교외접속(프록시)은 어떻게 설정하나요?

- ⚙설정 › 검색·원문 › **'도서관 경유 URL'** — **칸 하나**입니다('도서관 홈페이지' 칸과 '항상 도서관 경유' 체크란을 뺐습니다). 이 주소 하나가 로그인 페이지와 경유 여부를 함께 정합니다.
- **목록에서 소속 기관을 고르면 끝납니다**(34개 기관). 옆의 **[확인]** 으로 그 주소가 실제로 응답하는지 눌러 볼 수 있습니다.
- 목록에 없으면 주소를 직접 넣습니다. 형식은 **자동 인식**됩니다 — 교외에서 DB 를 눌렀을 때 나온 주소를 그대로 붙여넣으면 템플릿으로 변환.
  - 경로형 예: `https://proxy.○○.ac.kr/_Lib_Proxy_Url/` → `{urlraw}`
  - 쿼리형 예: `https://proxy.○○.ac.kr/login?url=` → `{url}`
- ⚠ **호스트가 이미 치환된 주소**(`https://www-sciencedirect-com.proxy.○○.ac.kr/…`)는 붙여넣지 마세요 — 리다이렉트 **결과**라 템플릿이 되지 못합니다. 도서관 DB 목록에서 **링크 주소 복사**로 원본을 얻으세요.
- 프록시는 로그인하지 않은 접근을 거부하므로 '로그인 열기' 로 먼저 로그인해 세션을 만드세요.
- KCI 무료 원문은 로그인 없이 자동 확보됩니다.
- 제목이 조금 달라도 찾습니다. KCI 문서번호·주소·DOI 가 없으면 제목으로 찾는데, 표기가 한 글자만 달라도 못 찾던 것을 고쳤습니다. 잘못된 문헌을 붙이지 않도록 연도와 제1저자가 같을 때만 받아들입니다.

## 여러 논문의 원문을 한꺼번에 받으려면?

- `서재` › '원문 일괄 확보'(PDF 없는 문헌 전체) 또는 목록 다중 선택 후 우클릭 '원문 확보 (N건)'.
- 순차 진행 + 진행률·예상 남은 시간 표시, 완료 후 '확보/구독DB/미확보' 브리핑.

## 학위논문 원문은?

- 무료 기관 리포지터리 경로(RISS → dCollection)를 자동 추적해 첨부(프록시·로그인 불필요).
- 대학별 이용 동의·DRM 으로 막히면 브라우저로 상세를 열어 주고, 다운로드하면 폴더 감시로 자동 첨부.

## 여러 건을 동시에 받으면 엉뚱한 논문에 붙지 않나요?

- 받은 PDF 를 **파일 이름의 제목 → 저자·연도 → ISBN → 첫 쪽의 DOI·제목** 순으로 맞춰, 하나로 정해질 때만 자동 첨부합니다.
- 정하지 못한 것은 원문 확보 창 안의 **'받은 PDF'** 줄(또는 상태줄 **📎 확인 대기**)에서 골라 붙입니다. 확보와 무관해 보이는 PDF 는 붙이지 않습니다.

## 앱은 못 찾았는데 도서관 검색으로 원문 URL 을 찾았어요.

- 실패 팝업의 '원문 URL로 확보…' 에 그 주소(또는 도서관 프록시 주소)를 붙여넣기 → 브라우저로 열림 → 받으면 자동 첨부.
- 코리아스콜라 등 KCI·RISS 에 안 잡히는 DB 에 유용합니다.

## 번역서·연구보고서 서지와 알라딘 연동은 어떻게 처리하나요?

국중도 상세 서지에서 확인한 번역서의 원저자 이름은 원어로 저장하고, 번역서명·원제·역자·편저자를 구분합니다. 원어 근거가 없으면 추정하지 않으며 직접 수정한 정보는 보존합니다. 연구보고서의 책임·공동 연구진과 보조 인력도 구별합니다. 알라딘 연동은 종료했으며, 카카오·국중도 보완과 기존 저장 서지는 유지합니다.

## 첨부한 PDF 를 앱 안에서 보고 주석을 달 수 있나요?

- 네 — 상세 패널의 첨부를 클릭하면 **앱 안 PDF 뷰어**(별도 창).
- 확대/축소 · 폭·쪽 맞춤 · 한쪽/두쪽 보기 · 페이지 이동 · 인쇄(주석 포함).
- **인쇄**: 툴바 **[인쇄]** 또는 `Ctrl+P`로 화면 확대율과 관계없이 고해상도로 인쇄합니다. A4 세로 영역에 쪽별로 맞추고 주석 위치를 유지합니다. 전체 쪽을 준비하며 준비 중 `Esc`로 취소할 수 있습니다. 주석이 있으면 마지막에 주석 모음을 붙입니다. PDF로 인쇄 저장한 본문은 이미지이며, 원래 PDF는 그대로 유지됩니다.
- 주석: 드래그 후 우클릭 또는 `H`(하이라이트)·`U`(밑줄)·`N`(메모), 색 선택 가능.
- 저장 위치: PDF 옆 `<파일명>.annots.json` 사이드카 → 서재 동기화를 따라감.
- 사이드바 **'주석 검색'** 으로 서재 전체 주석 검색.
- 주석·대화 패널의 글자는 골라서 복사할 수 있습니다.
- PDF 가 아닌 첨부는 OS 기본 앱으로 열립니다.

## 읽고 있는 논문에 대해 AI 에게 물어볼 수 있나요?

- 네 — PDF 뷰어 툴바 **[대화]** → 오른쪽 도크가 **`주석`·`대화` 두 탭**으로 갈립니다(손잡이로 폭 조절).
- 지금 읽는 논문 한 편만을 근거로 답하고, 이어서 되물을 수 있습니다. 문헌에서 확인되지 않는 내용은 답하지 않도록 지시합니다.
- 답변 속 **`(p.쪽)` 표기가 곧 버튼**이라 누르면 그 근거 자리로 갑니다. 쪽 번호는 모델이 적은 것을 믿지 않고 앱이 원문에서 되찾아 확정합니다.
- 답변이 생성되는 대로 표시됩니다(Claude CLI·Antigravity CLI). [중지] 하면 받은 데까지 남습니다.
- 입력은 `Ctrl+Enter` 전송. AI 제공자 설정이 필요합니다.

## 논문에 안 나오는 것도 물어볼 수 있나요?

- 네. 용어의 뜻, 그 방법의 통상적인 한계, 배경 같은 것은 논문 밖에 있습니다.
- 다만 **답이 어디서 왔는지 표시가 갈립니다** — 굵고 눌리는 **(p.9)** 는 앱이 **원문에서 실제로 찾아 확인한** 근거이고, **(일반 지식)** 은 논문 밖에서 온 것이라 쪽을 붙이지 않습니다.
- **(쪽 미확인)** 은 따옴표 친 인용인데 원문에서 못 찾았다는 뜻입니다. 인용하기 전에 확인하세요.

## 지난번에 물어본 것을 다시 볼 수 있나요?

- 네. 그 PDF 에서 나눈 대화가 남습니다. 창을 닫았다 열어도 이어서 물을 수 있고, 목록에서 옛 대화를 골라 되돌아갑니다.
- `새 대화` 는 새 대화를 시작하는 것이고 보관분과 지난 대화는 그대로 있습니다.
- 보관한 답변은 **'주석 검색' 에도 함께** 나옵니다(결과줄에 `주석 N · AI 대화 M`).
- 단, **주석 개수 배지와 인쇄 모음은 주석만** 셉니다.

## PDF 안에서 낱말을 찾고 싶어요.

- 뷰어에서 **`Ctrl+F`**. 열려 있는 PDF **전체**에서 찾습니다 — 아직 화면에 그려지지 않은 쪽도 포함합니다.
- **띄어쓰기·줄바꿈·대소문자를 무시**하므로 PDF 특유의 줄 끊김('교육
과정')에 걸리지 않습니다.
- `Enter`·`Shift+Enter` 로 다음·이전, `Esc` 로 닫습니다.

## 연결이 끊긴 PDF 가 쌓였어요.

- 첨부 '연결 해제' 는 파일을 지우지 않아 첨부 폴더에만 남습니다.
- 사이드바 *기타* › **'연결 안 된 PDF'** — 파일마다 **추천 서지와 근거**가 보이고, 행을 누르면 **첫 쪽 미리보기**와 PDF 에서 읽은 제목·저자·연도.
- 처리: **[연결…]**(자동 후보 · 서재 검색 · DB 검색 — 서재에 없으면 DB 에서 담으면서 연결) · 추천 있는 것 **일괄 연결** · **새 서지로 만들기** · [되돌리기].
- 삭제 대신 **격리 폴더**(`서재 폴더\_정리대기`)로 옮깁니다. 여러 PC 가 서재 폴더를 같이 쓸 때 다른 PC 가 쓰는 파일을 지우지 않기 위해서입니다.
