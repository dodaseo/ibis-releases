# 검색 · 수집

[자주 묻는 질문 목차](../FAQ.md)

## 무엇을 찾아야 할지부터 막막할 때는요?

- 찾기 줄 왼쪽의 [질문] 칩을 켜고 연구 질의를 문장으로 입력하면 국내외 DB 와 내 서재를 한 번에 검색해 관련도 순으로 보여 줍니다.
- 찾기 줄 아래 **체크 행**에서 어디서 찾을지 고릅니다: `전체` │ **내 서재** │ 국내(KCI·ScienceON·국립중앙도서관) │ 국외(OpenAlex·Crossref·ERIC·arXiv·PubMed). 행 오른쪽 끝에 예상 크레딧이 적힙니다.
- **내 서재 칸은 기본 꺼짐** — 꺼져 있으면 DB 에서만 찾고 이미 담은 것에는 [보관됨] 배지가 붙습니다. 켜면 서재 문헌도 순위에 함께 듭니다.
- **법·정책 다섯 갈래는 여기 없습니다** — 키워드로 찾기에서만 씁니다.
- 결과는 **키워드로 찾기와 같은 표**에 나옵니다 — 맨 왼쪽 관련도 칸(순위·막대·점수)만 질문으로 찾기에서 더 보입니다.
- 모은 후보(보통 200여 건)를 전부 채점해 100여 편을 보여 줍니다.
- 국립중앙도서관 단행본도 순위에 오릅니다. 책소개가 없으면 카카오 책에서 가져와 채점합니다.
- [최근 질의] 에서 누르면 크레딧 소모 없이 결과가 다시 표시됩니다.
- **질의에 적은 조건을 읽습니다** — `2015년 이후`·`학위논문만`·`OO 저자`·`OO학회지`·`양적 연구는 빼고` 처럼 문장 안에 넣은 기간·유형·저자·학술지·제외·선호가 그대로 DB 에 보내는 검색 조건이 됩니다.
- **여러 개 골라 한 번에 컬렉션으로** — Ctrl·Shift 클릭으로 고른 뒤 끌면 전부 갑니다. '많이 인용된·대표적인' 같은 조건도 해외 DB 피인용 수로 순위에 실제 반영됩니다.
- **사이드바를 누르면 질문 화면을 닫고 그 뷰로 갑니다** — 키워드로 찾기와 같습니다. 결과는 남아 있어 레일 아이콘으로 돌아오면 그대로입니다.
- 낱말로 찾는 것은 키워드로 찾기, 문장으로 묻는 것은 질문으로 찾기입니다.

## '외부 검색'·'DB 검색' 이 안 보여요.

- 지금 이름은 **키워드로 찾기** 입니다. '외부 검색'(~2026.9.6) → 'DB 검색'(2026.9.7) → **'키워드로 찾기'**(2026.9.8) 로 이름만 바뀌었고 하는 일은 같습니다.
- **레일에는 '질문으로 찾기' 아이콘이 따로 없습니다.** 레일의 찾기 아이콘 셋(**찾기(학술) · 법·정책 · 통계**)은 *어디서* 찾을지고, 낱말/문장은 찾기 줄 왼쪽의 **키워드 | 질문** 칩으로 고릅니다(질문은 학술·통계에서만).
- 화면도 바뀌었습니다 — 예전에는 이 모드에서 사이드바가 소스 목록이었는데, 이제 **세 모드(서재·키워드로 찾기·질문으로 찾기)가 같은 서재 사이드바**를 쓰고 **찾기 줄과 DB 체크 행도 같은 자리**입니다. 사이드바의 컬렉션을 누르면 그 뷰로 갑니다.
- 질문으로 찾기의 결과도 이제 **같은 표**에 나옵니다 — 맨 왼쪽 관련도 칸만 거기서 더 보입니다.

## 두 찾기의 DB 목록이 서로 다릅니다.

- **같습니다** — 키워드·질문 두 모드가 같은 목록(내 서재 칸·S2 포함)을 쓰고 **같은 조합을 기억**합니다(한쪽에서 끄면 다른 쪽도 꺼져 있습니다). 법·정책과 통계는 별도 레일 아이콘(범위)이라 학술 목록에 섞이지 않고, 조합은 범위마다 따로 기억됩니다. 통계는 KOSIS 하나라 체크 행 대신 안내 한 줄입니다.

## 통계(KOSIS)도 찾을 수 있나요?

- 레일의 **통계** 아이콘(막대)입니다. 키워드로 찾으면 통계표 목록(한 번에 최대 20건 — 검색어를 좁히세요), **[질문]** 칩을 켜고 문장으로 물으면 조사 개요·항목·분류 이름으로 관련도를 매기고 상위 표의 **최근 수치**를 행에 미리 보입니다. 표를 열면 **[수치 보기]**(시점 × 분류·항목 표 · CSV 저장), 담으면 **데이터세트**로 인용됩니다(인출일 자동). 같은 표의 연도별 판은 최신 하나로 합칩니다.

## 저자 이름으로 물었는데 관련도 칸이 비어 있어요.

- 정상입니다. "○○의 연구물을 찾아줘" 처럼 주제 없이 사람이나 학술지만 물으면 저자 검색으로 가고 최신순으로 정렬됩니다. 관련도는 주제의 일치 정도를 재는 값이라 저자 검색에는 맞지 않아 매기지 않으며, 크레딧도 들지 않습니다.

## 어떤 검색 소스를 쓸 수 있나요?

- 학술 **9종** — 국내: KCI · ScienceON · 국립중앙도서관 / 해외: OpenAlex · Crossref · ERIC · arXiv · Semantic Scholar · **PubMed**.
- 여기에 **법·정책 5갈래** — 법령 · 판례 · 정책자료 · 법률안 · 회의록. 위 「법령·판례·정책자료도 찾을 수 있나요」 참고.
- PubMed 는 미국 국립의학도서관의 의학·보건·간호 DB(초록·MeSH 주제어 포함). 주제 범위가 좁아 **arXiv 처럼 기본 꺼짐**이고 필요할 때 켭니다(S2 도 키워드로 찾기에서 기본 꺼짐).
- 어디서 찾을지는 **검색줄 아래 체크 행**에서 고릅니다 — `전체 │ 국내 │ 국외`. '국내'·'국외' 글자를 누르면 묶음이 통째로 켜지고, 원하는 대로 섞어도 됩니다. 둘 이상이면 병렬 질의 후 중복 병합하고, 고른 조합은 기억됩니다.
- ERIC 은 미국 교육부 IES 가 운영하는 교육학 DB(저널논문·문서/보고서), 키 불필요.
- 모두 설치 직후부터 쓸 수 있습니다. 발급받을 키가 없습니다.

## 국립중앙도서관은 어떤 자료를 찾나요?

- **학위논문·도서·연속간행물·웹자료** 등 국내 발행물. 학술논문은 KCI 쪽입니다.
- 유형을 안 고르면 네 갈래를 동시에 검색합니다.
- 학위논문은 **최신까지** 나옵니다(소장자료 색인 기반). 정렬을 안 골라도 최신부터 보여 줍니다.
- 연구보고서 저자의 역할 표기(책임연구원·공동연구원 등)는 제거하고 이름만 남깁니다. 주관·협력 기관은 저자가 아니라 펴낸 곳으로 다루고(사람이 하나도 없으면 단체저자로 올립니다), 연구조원·연구운영원은 저자로 세지 않습니다.
- ⚠ **'단행본'·'보고서' 유형은 그 갈래의 일부만** 찾습니다 — 자료구분을 한 번에 하나만 보낼 수 있어 단행본=일반도서만, 보고서=정부간행물만 조회됩니다(아동도서·교과서·공공간행물 등은 빠짐). 앱이 결과줄에 매번 밝힙니다.

## 법령·판례·정책자료도 찾을 수 있나요?

- 네. 체크 행의 **셋째 묶음 [법·정책]** 입니다 — **법령 · 판례**(법제처 국가법령정보)와 **정책자료 · 법률안 · 회의록**(국회도서관) 다섯 갈래. 설정할 것은 없습니다.
- 칸 하나가 **한 인용 갈래**라 담으면 바로 참고문헌 서식이 나옵니다 — `교육부 (2026). 초ㆍ중등교육법. 법률, 제21659호(시행 2026. 8. 20.).`
- 법·정책을 켜면 학술 DB 는 함께 검색하지 않습니다. 결과가 섞이면 구분해 찾는 의미가 없기 때문입니다.
- 정렬은 **관련도순 하나**뿐입니다(두 API 다 정렬 인자를 받지 않습니다).
- 질문으로 찾기에서는 쓰지 않습니다. 갈래마다 채점에 쓸 수 있는 본문 길이가 크게 달라 순위가 한쪽으로 치우치기 때문입니다. 키워드로 찾기에서만 씁니다.

## 사람 이름으로 검색했는데 0건이 나와요.

- 검색창에 입력한 말은 KCI 에 제목·저자·키워드 세 갈래로 나눠 질의하고 합칩니다.
- 대신 이 합집합 검색은 **약 540건**에서 끝납니다. 더 깊이 넘겨 봐야 하면 필드를 지정하세요(상위 10,000건까지).

## DOI 만 있는 논문을 빠르게 추가하려면?

- 상단 검색창에 DOI(또는 doi.org 링크) 붙여넣기 → 소스와 무관하게 1건 즉시 해석.
- 또는 `새 문헌 추가` 창의 **식별자로 채우기** 칸에 넣고 **[바로 저장]** → 바로 내 서지에 보관.
- doi.org content negotiation 사용 — 등록기관 무관, 키 불필요.

## 여러 DB 로 검색할 때 하나가 실패하면?

- 나머지는 계속 진행되고, 결과 제목줄에 실패한 소스명이 표시됩니다.
- 요청 제한에 걸린 소스는 '실패'가 아니라 '잠시 뒤 다시'로 표시합니다.
- 중복 병합 기준: **DOI 우선**, 없으면 정규화 제목+연도.

## 질문으로 찾기가 늘 20초쯤 걸렸는데요.

- 2026.9.15 에서 고쳤습니다. arXiv 가 응답하지 않을 때 전체가 기다리던 것을, 응답이 없으면 바로 건너뛰고 한동안 다시 묻지 않도록 바꿨습니다.
- 2026.9.16 에서는 해외 DB 에 검색어를 동시에 보내도록 바꿔 수집 시간이 19초에서 9.2초로 줄었습니다.

## 검색 결과가 20건에서 안 늘어나요.

- 외부 소스는 페이지당 20건 — 하단 페이지 바(‹ 1 2 3 … ›)로 이동.
- 페이지를 넘겨도 이전 결과는 인용 대상으로 유지.
- 열람 상한: 국립중앙도서관은 한 갈래마다 500건(유형 미지정이면 합쳐 최대 2,000건), KCI 는 10,000건, 합집합 검색은 1,000건.
- '내 서지' 검색은 전체를 한 번에 보여줘 페이지 바가 없습니다.

## 목록 머리의 '총 465건' 은 뭔가요? 어떤 검색은 왜 안 적히나요?

- `20건 (총 465건)` — 지금 보이는 건수와 그 검색의 전체 건수입니다.
- **총건수를 알려주지 않는 소스**(Crossref·OpenAlex·Semantic Scholar·arXiv·ERIC)는 숫자를 **아예 적지 않습니다** — 0 으로 채우면 진짜 0건과 구분되지 않기 때문입니다.

## 조건을 여러 개 걸어 검색하려면? (고급검색)

- `[그리고/또는] [필드] [포함/정확히 이 구] [값]` 조건 줄을 ＋로 쌓습니다(한 묶음 8줄, 「또는」 묶음 3개까지). **「그리고」가 먼저 묶입니다.**
- 필드 그룹: **공통**(전체·제목·저자·발행처·학술지·키워드) / **KCI 전용**(DOI·저자 소속기관·발행기관) / **국립중앙도서관 전용**(ISBN·ISSN·분류기호·자료구분·수록연도) / **내 서지 전용**(초록·첨부파일명).
- 전용 필드를 고르면 **체크 행이 그 DB 로 바뀝니다.**
- 고급검색을 열면 검색창의 글자가 첫 조건 줄로 옮겨 갑니다(닫으면 되돌림). 어느 DB 에서 찾을지는 고급검색 안이 아니라 **검색줄 아래 체크 행**입니다(그전에는 고급검색 안의 소스 드롭다운).
- 다중 조건을 못 받는 소스: ScienceON 과 해외 소스 전부.

## 고급검색에 초록 검색과 제외(NOT)가 없어요.

- KCI 는 초록 조건을 실제로 적용하지 않고, 국립중앙도서관 응답에는 초록 필드가 없습니다. 적용되지 않는 조건을 보여 주면 오해를 낳기 때문에 뺐습니다.
- 초록 검색은 **'내 서지'** 에서만 됩니다.

## 국내 논문인데 영문 제목·저자만 나와요.

- 일부 저널이 영문 서지만 제공합니다.
- 저장 시 DOI 가 있으면 **KCI 로 국문 제목·학술지·한글 저자를 보강**하고, 영문은 병기 필드(`title_en`·`container_en`·`authors_en`)로 보존.
- 그래도 비면 상세 패널에서 직접 수정.

## 이미 담긴 서지의 저자·제목이 틀렸어요. 고쳐지나요?

- **직접 고칩니다** — 상세 패널이나 `문헌` 메뉴 › **서지 편집(F2)**. 고친 값이 곧 인용·참고문헌에 쓰입니다([내 서지에서 고치면 문서에도 반영되나요?](02-cite.md#내-서지에서-고치면-문서에도-반영되나요)).
- 동료와 컬렉션을 나누고 있어도 **내가 고친 칸은 지켜집니다**(칸 단위 병합).
- 앱이 오류를 자동으로 찾아 고치지는 않습니다. 담을 때 DB 가 준 값을 그대로 쓰고, 검증 기능은 없습니다. 인용할 문헌의 서지는 직접 확인하세요. 특히 저자 표기와, 학회 발표문과 학술지판처럼 제목·저자가 같아도 다른 문헌인 경우를 확인하세요.

## 내 서지 검색은 어디까지 검색하나요?

- 제목·저자·수록처·태그·키워드·AI 요약(노트)·초록·영문 병기 + **첨부 파일명**까지 전문검색(FTS5).
- 검색어 3자 미만이면 제목·수록처만 보는 단순 매칭으로 폴백.
- 고급 검색에서 필드를 좁히면 그 필드만 봅니다.
- 첨부 PDF 본문도 검색합니다. 제목·초록에 없는 낱말이 PDF 에 있으면 그 문헌이 뒤에 추가되고 행 아래 발췌 한 줄이 보입니다. 고급 검색의 **본문(PDF)** 필드로 본문만 볼 수도 있습니다. 색인은 첨부 뒤 배경에서 저절로 만들어지고, 상태는 ⚙설정 › 서재 › PDF 본문 색인.

## EndNote(.enw)·RefWorks·엑셀 표도 가져올 수 있나요?

- 가져오기 **6형식**: RIS · BibTeX · CSL · EndNote(.enw) · RefWorks · Tab(.tsv/.csv).
- 파일 대화상자 기본 필터는 RIS·BibTeX·CSL — '모든 파일' 로 바꾸면 나머지도 처리.
- `새 문헌 추가` 창의 붙여넣기 상자는 6형식 **자동 인식**(끌어놓기 가능).
- **내보내기는 CSL-JSON(.json)·BibTeX(.bib) 2종만**.

## 붙여넣은 인용문이 엉뚱한 논문으로 채워지지 않나요?

- Crossref '서지 매칭' 을 **쓰지 않습니다**(무관한 논문이 채워지는 것을 막기 위해).
- 본문에 DOI 가 있으면 그것만 해석, 없으면 텍스트에서 저자·연도·제목·수록처·권호쪽을 분해.
- 인식 실패 시 값을 채우지 않고 빈 양식 유지 → 직접 입력.
