# 인용 스타일

[자주 묻는 질문 목차](../FAQ.md)

## 내장 스타일은?

- 엔진 **6종** — **APA 7**(저자-연도, 국문 가나다 먼저 → 서양 알파벳) · **IEEE**(번호형·7인 이상 et al.) · **Chicago 17 저자-연도**(`(Smith and Lee 2020, 23)`) · **MLA 9**(연도 없는 `(Smith and Lee 23)`) · **Vancouver**(번호형 [n], 등장순) · **번호형 [n]**(본문 [n] + APA 형식 참고문헌).
- 내장 **저널 스타일 2종** — `APA 6판` · `교육사회학연구`.
- 기본값 APA 7. 엔진 6종은 저널 스타일의 '부모 엔진' 후보이기도 합니다.

## 새 학술지 스타일을 추가하려면?

- ⚙설정 › 인용 › 인용 스타일 › '스타일 관리…' › `＋ 새 저널 스타일`.
- 부모 엔진 + 파라미터(저자 축약·구분자·제목 따옴표·유형×언어 강조·DOI 등) 지정.
- 또는 '원고 세칙 AI 분석' 으로 투고규정을 붙여넣어 초안 자동 생성 후 확인·수정.

## 만든 스타일을 다른 PC·동료와 공유하려면?

- 서재 폴더의 `journal_styles/<id>.json` 파일입니다.
- 서재를 클라우드에 두면 자동 동기화, 파일만 복사해 전달해도 됩니다.

## 내장 스타일을 고칠 수 있나요?

- 내장 스타일 자체는 삭제 불가.
- 편집기에서 **같은 이름으로 저장**하면 같은 id 의 '사용자 판' 이 우선 적용.
- 사용자 판을 삭제하면 내장 스타일 복원.

## Vancouver 부모 저널 스타일에서 저자 축약·강조 설정이 적용되나요?

- 적용됩니다. 저자 축약·강조·DOI 표기·쪽 표기 모두 반영됩니다.
- 밴쿠버 자체 기본값(저자 7인 이상이면 6인 + et al., 무강조)이 있고, 저널 스타일이 명시한 항목만 그 위에 적용됩니다.
- 본문 표기는 [n] 고정입니다(번호형 엔진도 마찬가지).

## 밴쿠버에서 쪽수를 함께 인용하면?

- `[1](p23)` 로 나옵니다. `[1, 23]` 은 1번과 23번 문헌으로 읽힐 수 있어 쓰지 않습니다.

## 밴쿠버 참고문헌에서 단행본·학위논문에 발행처가 빠져요.

- 단행본·보고서는 발행처, 학위논문은 수여기관이 출력됩니다.
- ⚠ 이미 밴쿠버로 뽑아 둔 목록이 있다면 갱신 시 그 줄이 달라집니다.

## 갱신했더니 2020a·2020b 순서와 접미사가 바뀌었어요.

- 같은 저자·같은 해의 `a`/`b` 를 참고문헌에서 **제목순**으로 바로잡았습니다(APA 7판 §9.47).
- 기존 문서를 '전체 갱신' 하면 그 부분의 순서·접미사가 **한 번 바뀝니다.** 이후로는 그대로 유지됩니다.

## 국문 제목만 따옴표를 붙이는 규정도 되나요?

- 됩니다 — '논문 제목 따옴표' 에서 국문·영문을 각각 지정(예: 국문 「 」, 영문 없음).
- 강조도 '유형×언어' 매트릭스로 분리 지정(국문 단행본 밑줄 · 영문 단행본 이탤릭 등).

## 참고문헌 DOI 표기를 끄려면?

- 저널 스타일 편집기 › 'DOI 표기' 체크박스(기본 켜짐, 내장 '교육사회학연구' 는 미표기).
- DOI 가 없고 URL 이 있으면 URL 로 대체 표기.

## 곧은 따옴표가 둥근 따옴표로 바뀌어요.

- 정상 — 출력 시 문맥에 맞춰 여닫이(' ' · " ")로 자동 정규화. 아포스트로피는 오른작은따옴표.
- 별도 설정 항목 없음.

## 원고 세칙 AI 분석에 필요한 것은?

- ⚙설정의 AI 제공자(구독 CLI 또는 API 키).
- 입력 형식: 텍스트 붙여넣기 · URL · 파일(PDF/DOCX/HWPX).
- 규정에 **명시된 항목만** 파라미터로 변환합니다.
- 레거시 `.hwp` 는 자동 추출이 어려워 한글에서 열어 본문을 복사하는 편이 확실합니다.

## 미리보기에 한글 실행이 필요한가요?

- 아니요 — 내장 샘플 문헌으로 계산해 렌더하므로 한글 실행·문서 연결 없이 즉시 확인됩니다.

## 문헌 상세의 '스타일 미리보기' 가 실제 문서와 다르게 보여요.

- 같습니다. 문서에 들어가는 것과 같은 결과를 보여 줍니다.
