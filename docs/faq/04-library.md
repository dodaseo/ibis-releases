# 서지 관리 · 컬렉션 · 태그

[자주 묻는 질문 목차](../FAQ.md)

## 여러 PC(집·연구실)에서 같은 서재를 쓰려면?

- 사용하는 모든 PC를 2026.10.1.0 이상으로 업데이트하고 같은 구글 계정으로 로그인합니다.
- `⚙설정 › 클라우드`의 **내 서재 동기화**를 켭니다. 서지·컬렉션·개인 메모·즐겨찾기는 Ibis가 맞춥니다.
- PDF도 함께 쓰려면 `⚙설정 › 서재 › 열기`에서 사용자 클라우드의 같은 서재 폴더를 선택합니다. PDF·문서 저장소·저널 스타일은 그 폴더에 유지됩니다.
- Ibis 동기화가 연결된 서지와 동기화 기록은 PC별로 따로 보관합니다. 사용자 클라우드와 Ibis가 같은 작업 파일을 동시에 갱신하지 않습니다.
- 최신 전체 백업은 앱의 **서재 사본 저장**을 사용합니다. API 키·AI 설정·테마는 PC별 설정입니다.

## 어느 날 갑자기 첨부 PDF 가 하나도 안 보여요.

- 대부분 앱이 다른 서재를 열고 있는 경우입니다. ⚙설정 › 서재의 **서재 위치**가 쓰던 폴더인지 보세요. 다른 곳이면 **[열기]** 로 원래 폴더를 고르면 서지·첨부·문서 인용 기록이 그대로 돌아옵니다(파일은 지워진 게 아닙니다).
- 내 서재 동기화가 켜져 있으면 새로 생긴 빈 서재가 서버 사본으로 채워져 '서지는 다 있는데 첨부만 없는' 모양이 됩니다 — PDF 는 어느 동기화에도 올라가지 않기 때문입니다.
- 서재가 바뀔 때 `%LOCALAPPDATA%\Ibis\library_switch.log` 에 기록이 남습니다. 서재 위치가 기본값으로 되돌아가던 원인(설정 파일 덮어쓰기)도 고쳤습니다.
- 서지를 실수로 지웠거나 이전 상태로 돌아가야 하면 `⚙설정 › 서재 › 백업` 목록에서 그 날짜의 **[복원]** 을 누르세요. 서재는 하루 한 번 이 PC 에 자동으로 백업됩니다(최근 14개, PDF 파일 제외).

## '새로 만들기'·'열기'·'사본 저장' 차이는?

- **새로 만들기** — 빈 폴더에 새 서재 생성 후 전환(이미 있으면 오류). 확인문이 먼저 뜹니다(지금 서재의 서지 건수 · 첨부는 따라오지 않음 · 이어 쓰려면 [열기] · 동기화가 켜져 있으면 새 서재가 서버 사본으로 채워진다는 것).
- **열기** — 기존 서재에 복사 없이 연결·전환(없으면 오류). 다른 PC 의 클라우드 서재에 붙을 때.
- **사본 저장(백업)** — 다른 폴더로 복사만, 전환하지 않음.
- **자동 백업**은 따로 있습니다 — 하루 한 번 이 PC 에 남고, 같은 탭의 '백업' 목록에서 [복원] 합니다.
- 앞의 둘은 전환 전에 현재 서재를 자동 저장합니다.

## 컬렉션과 스마트 컬렉션의 차이는?

- **컬렉션** — 직접 드래그해 넣는 수동 폴더(계층·색 지정).
- **스마트 컬렉션** — 조건(검색어·저자·태그·연도·유형)을 저장해 자동으로 모이는 동적 묶음.
- 문헌을 추가·수정하면 스마트 쪽은 자동 갱신, 일반 컬렉션은 직접 관리.

## 태그는 어디서 걸러 보나요?

- 별도 태그 사이드바는 없습니다 — 레일의 그래프 아이콘 → **태그 그래프 뷰**.
- 태그 노드 클릭 → 그 태그의 문헌이 중앙 목록에.
- 상단 스코프(전체/컬렉션/스마트/문서)로 범위 조절.

## 그래프에 태그가 하나도 안 나와요.

- 노드는 태그이므로 문헌에 태그가 있어야 보입니다.
- 상세 패널에서 직접 입력하거나, 우클릭 › 'AI 요약' 으로 자동 생성(AI 설정 필요).
- 스코프가 좁혀져 있으면 비어 보일 수 있으니 '전체 서지' 로 확인.

## 태그가 'BERTopic' 과 '버트토픽' 으로 갈라졌어요.

- 그래프에서 태그 노드 우클릭 › '이름 변경·병합'.
- 여러 개를 한 번에: `서재` › 'AI 태그 정리…' — AI 가 음차·번역·띄어쓰기 차이의 병합안을 제안하고 **적용할 묶음만 골라** 반영(AI 는 제안만).

## 같은 주제 컬렉션을 여러 번 만들어 나뉘었어요.

- 사이드바에서 **Ctrl+클릭**(범위는 Shift+클릭)으로 둘 이상 고르고 우클릭 › **[선택한 N개 합치기…]** → 어느 것을 남길지 고릅니다.
- **문헌은 지워지지 않습니다** — 컬렉션 구성만 바뀌고 양쪽에 있던 문헌은 한 번만 남습니다.
- 없어지는 컬렉션의 **하위·스마트 컬렉션은 남는 컬렉션 밑으로** 갑니다.
- ⚠ **클라우드로 공유 중인 컬렉션은 없어지는 쪽이 될 수 없습니다** — 서재에서 사라지면 동료와의 공유가 끊기기 때문입니다.

## 실수로 삭제한 문헌을 되살릴 수 있나요?

- 삭제는 휴지통으로 이동 — '휴지통' 뷰에서 우클릭 › '복원'(컬렉션 소속까지 복구).
- '영구 삭제' 만 되돌릴 수 없습니다.

## 중복 논문을 한 번에 정리하려면?

- `서재` › '중복 문헌 정리'(확인창에서 승인) — DOI 또는 정규화 제목+연도가 같은 문헌을 **정보가 가장 충실한 1건**에 병합.
- 자동 처리: 빈 필드 보강 · 첨부/키워드 합침 · 컬렉션 이관 · ★·이른 추가일 승계.

## RIS·BibTeX 파일을 컬렉션에 끌어다 놓으면 그 컬렉션에 들어가나요?

- 네. 사이드바의 컬렉션이나 컬렉션 화면에 서지 파일을 떨구면 **그 컬렉션에** 담깁니다. 이미 서재에 있던 문헌은 합쳐지고, 그것도 그 컬렉션에 배정됩니다.
- 검색 결과 행을 컬렉션에 끌어 놓으면 보관과 배정이 한 번에 됩니다. 행의 제목 칸을 잡고 끄세요.

## 검색으로 안 나오는 국역서·법령을 넣고 싶어요.

- 사이드바 맨 위 [새 문헌 추가] › '새 문헌 추가…' → 인용문이나 DB 내보내기 파일을 붙여넣고 '파싱하여 추가'.
- 없으면 유형(단행본·법령·조례 등)을 골라 직접 입력 → 인용키 자동 생성.

## 신문기사나 웹 문서를 인용해야 합니다. 다 손으로 적나요?

- 아닙니다 — `새 문헌 추가` 창의 **식별자로 채우기**(DOI·ISBN 을 넣던 그 칸)에 **주소를 그대로 붙여넣으세요.**
- 제목·매체명·저자·게시일을 채우고 **검색일을 오늘로** 넣습니다.
- 페이지가 표준 서지 정보를 내놓으면 그것을 쓰고, 없으면 **본문을 Ibis AI 가 읽어** 뽑습니다.
- 뽑은 값은 저장 전에 화면에서 고칠 수 있습니다. 언론사 페이지는 형식이 제각각이므로 확인하세요.

## 로그인해야 보이는 기사·웹 페이지는요?

- 서지 직접 추가 창의 **[브라우저로 열기]** 로 앱 안 브라우저를 띄워 직접 로그인·이동한 뒤 **[열린 페이지 담기]** 를 누르세요.
- 지금 떠 있는 페이지를 그 상태 그대로 읽어 제목·매체·저자·게시일을 채웁니다(주소 조회와 같은 방식). 스크립트로 그려지는 페이지도 됩니다.

## 컬렉션을 동료와 나누고 싶어요.

- 두 방식이 있습니다. 파일은 한 번 전달하는 방식, 클라우드는 계속 동기화하는 방식입니다.
- **파일** — 컬렉션 우클릭 › [공유 파일로 내보내기 (.ibiscol)…] → 메일·USB 로 전달 → 받는 쪽은 [공유 컬렉션 가져오기 (.ibiscol)…]. 서버를 안 거치고 오프라인에서도 됩니다.
- **클라우드(베타)** — ⚙설정 › 클라우드에서 구글 로그인 → 컬렉션 우클릭 › [클라우드로 공유…] → [초대…] 에 상대 이메일. 서지를 고치면 저절로 맞춰집니다.

## 공유하면 내 PDF 와 메모까지 넘어가나요?

- **PDF 원문 파일은 나가지 않습니다**(저작권 — 받는 쪽이 자기 도서관 계정으로 확보합니다). **개인 메모와 즐겨찾기도 나가지 않습니다.**
- 나가는 것: 서지 · 컬렉션 구성 · **하이라이트와 메모** · Ibis 가 만든 AI 요약 섹션.
- 하이라이트는 위치와 문장으로 전달됩니다. 받는 쪽이 원문을 확보해 열면 판본이 달라도 문장으로 자리를 찾아 붙습니다.
- 클라우드는 초록도 올리지 않습니다(용량 때문입니다).
- ⚠ 이것은 **남에게 건넬 때**의 규칙입니다. 직접 켜는 **[내 서재 동기화 (여러 PC)]** 는 받는 쪽이 같은 계정의 나 자신뿐이라 **개인 메모·즐겨찾기·초록도 함께** 올라가고, 남에게는 나눌 수 없습니다(서버가 초대를 거절합니다). **PDF 원문은 거기서도 올라가지 않습니다.**

## 클라우드 공유에 가입해야 하나요? 무엇을 받아 가나요?

- 별도 가입은 없습니다 — **구글 로그인 하나**로 끝입니다.
- 받는 개인정보는 **이메일 주소 1개**(참가자 식별·초대용)뿐입니다. 로그인 창의 **[개인정보 처리방침 보기]** 로 로그인 전에 확인하실 수 있습니다.
- 베타 동안 무료입니다. 상태줄의 `☁`에서 동기화 상태를 확인합니다. 서버 보호를 위한 제한에 닿아 동기화를 완료하지 못하면 그 사실을 알리며, 이 PC의 서지는 그대로 보관됩니다.

## 내 서재 전체를 여러 PC 에서 맞출 수 있나요?

- 네 — `⚙설정 › 클라우드` › **[내 서재 동기화 (여러 PC)]** (베타). 같은 구글 계정으로 로그인한 내 다른 PC 와 **서재 전체**를 맞춥니다.
- **동기화하는 모든 PC를 2026.10.1.0 이상으로 판올림하세요.** 구버전을 함께 쓰면 스마트 컬렉션·서재 설정이 누락될 수 있습니다. 이미 모든 사본에서 사라진 값은 복원하지 못합니다.
- 컬렉션 공유와 달리 **개인 메모·즐겨찾기·초록도 함께** 갑니다(받는 쪽이 나 자신이므로). **남과는 나눌 수 없습니다** — 서버가 초대를 거절합니다.
- 다른 PC 에서 이미 켰다면 **그것을 먼저 받아 합칩니다.** 한쪽에서 지운 문헌·컬렉션은 다른 PC 에서도 정리됩니다(문헌은 휴지통으로, 컬렉션이 없어져도 그 안의 문헌은 서재에 남습니다).
- **PDF 원문 파일은 올라가지 않습니다.** 파일까지 맞추려면 서재 폴더를 클라우드 폴더에 두는 방식을 **함께** 쓰세요(권장 구성).
- **PDF 개인 클라우드 보관은 준비 중입니다** — 내 다른 PC 에서 PDF 원문까지 받을 수 있게 하는 기능으로, 지금은 일부 계정에서 시험하고 있습니다. 일반 사용자의 PDF 는 서버로 올라가지 않습니다. 이 보관은 내 PC 끼리만 쓰는 것이고, 컬렉션 공유로 PDF 를 남에게 건네는 기능은 만들지 않습니다.
- 컬렉션의 **이름·부모·색·순서·숨김**, **스마트 컬렉션**, **기본 인용 스타일과 서재 옵션**도 옮겨집니다. 접힘 상태·휴지통·PDF 본문 색인은 PC 마다 따로입니다.
- 끄기는 기본이 이 PC 연결만 끊기이고, 원하면 서버 사본까지 지울 수 있습니다.

## 클라우드로 함께 고치는데 상대가 고친 값이 안 보여요.

- **서지 교정은 칸 단위로 오갑니다**. 지난 동기화와 견주어 **내가 손대지 않은 칸**을 동료가 고쳤으면 받아 오고, **내가 고친 칸**은 지킵니다. 서로 다른 칸을 고친 것은 둘 다 삽니다.
- **같은 칸을 둘이 다르게 고친 경우에만** 나중 것으로 맞추고, **무엇이 덮였는지 동기화 결과에 알립니다.** 다만 시각 비교가 문헌 단위라 같은 날 안의 순서는 구분하지 못합니다. 중요한 교정은 서로 알려 주세요.
- 컬렉션의 이름·색·정렬 순서를 바꾼 것은 전파되지 않습니다(베타 한계). 참가자마다 달라지는 것을 막기 위해 제외했습니다. 문헌을 넣고 빼는 것은 정상으로 오갑니다.

## 공유를 그만두려면?

- 컬렉션 우클릭 › **[클라우드 공유 해제…]**. **소유자**는 *서버에서 없애기* 와 *이 PC 연결만 끊기* 중에 고릅니다.
- **참가자**는 **[공유에서 나가기]** 입니다.
- 누가 들어와 있는지와 나간 초대 링크는 우클릭 **[참가자·초대 관리…]** 에서 보고 끊습니다.

## 목록 정렬은?

- 컬럼 헤더(저자·연도·제목·수록처·유형) 클릭 → 정렬, 다시 클릭 → 오름/내림 토글(▲▼ 표시).
- 연도는 기본 내림차순, 텍스트 컬럼은 기본 오름차순.
- 헤더 경계를 드래그하면 폭 조절, 더블클릭하면 기본 폭 복원.
