## 1. 시작하기 — 한글/Word 연결

문서에 인용을 꽂으려면 실행 중인 한글 또는 Word 문서에 연결해야 합니다. 연결은
**우측 상단의 모드 배지**로 합니다.

- **한글/Word에서 작업할 문서를 먼저 엽니다.** Ibis는 워드프로세서를 **대신 실행하지 않고**,
  이미 열려 있는 앱에만 연결합니다.
- 앱을 켤 때 한글/Word가 이미 떠 있으면 **자동으로 활성 문서에 연결**됩니다(한글 우선).
  아무것도 안 떠 있으면 **독립 모드**로 시작합니다.
- **모드 배지를 클릭**하면 열린 문서를 골라 연결합니다. 문서가 하나면 바로 연결되고,
  한글·Word가 둘 다 켜져 있으면 먼저 **연결할 앱(한글/Word)**을 고른 뒤 문서를 선택합니다.
- 연결되면 배지에 **`한글 모드 · 파일명`**처럼 연결 문서명이 표시됩니다.
- 문서를 닫거나 다른 문서로 바꾼 뒤에는 **배지를 다시 눌러** 현재 문서를 선택하세요.

> **독립 모드**에서도 검색·서지관리·스타일 설정은 모두 됩니다 — 문서에 직접 인용을 꽂는
> 기능만 막힙니다. 이때 인용 스타일을 바꾸면 앱 전체 기본 스타일이 바뀌고, 이후 새로
> 연결하는 빈 문서가 그 기본을 물려받습니다.

## 2. 서지 수집 — 검색·DOI·가져오기

**검색.** 상단 검색창에 입력하고 오른쪽 드롭다운에서 소스를 고릅니다.

| 소스 | 특징 |
|---|---|
| 내 서지 | 보관 문헌 전체를 **광역 전문검색(FTS)** — 아래 참고 |
| KCI | 국내 등재지·학위논문 — [API 키 필요](FAQ.md#kciscienceon-api-키는-어떻게-받나요) |
| ScienceON | KISTI 통합(국내 학위논문 포함) — API 키 필요 |
| Crossref / OpenAlex / S2 / arXiv | 해외 학술 DB — 키 불필요 |
| ⚡멀티 | 여러 소스 동시 검색 후 중복 병합(출처 누적 표시) |

- **KCI·ScienceON은 API 키가 ⚙설정에 등록돼 있을 때만** 소스 목록에 나타납니다.
  기본 소스는 Crossref(무료)입니다.
- **내 서지 전문검색(FTS):** 제목·저자뿐 아니라 **수록처·태그·키워드·AI 요약(노트)·초록·영문
  병기**까지 훑습니다(예: AI 요약 본문에 있던 단어로도 찾힘). 검색어가 3자 미만이면 제목·수록처
  단순 매칭으로 폴백합니다.
- **고급 검색**(검색창 옆 '고급')으로 검색 필드·저자·연도 범위·학술지·정렬·문서 유형을 지정합니다.

**DOI 즉시 서지화.** 검색창에 `10.xxxx/...` 또는 `doi.org` URL을 붙여넣으면 소스와 무관하게
바로 서지로 해석됩니다. ⚙설정 하단 *DOI로 추가*에 넣으면 곧바로 내 서지에 보관됩니다.

**가져오기(6형식).** ⚙설정 → *가져오기* — **RIS·BibTeX·CSL·EndNote(.enw)·RefWorks·Tab**을
읽어들입니다(복수 파일 가능). Zotero·EndNote 등에서 옮겨올 때 사용하세요.

**내보내기(2형식).** ⚙설정 → *내보내기* — **CSL-JSON·BibTeX** 두 가지로 내보냅니다.

**중복 정리.** 🔧도구 → *중복 정리* — DOI 또는 정규화 제목+연도가 같은 문헌을 자동 병합합니다.
첨부·태그·★·추가일은 병합 시 보존됩니다.

## 3. 서지 정리 — 컬렉션·태그·휴지통

**컬렉션.** 사이드바 *컬렉션* 옆 ＋로 생성합니다. 우클릭으로 **색상 지정·이름 변경·
하위 컬렉션 추가·삭제**를 할 수 있고, 문헌을 **드래그해서 떨어뜨리면** 배정됩니다.
한 문헌을 여러 컬렉션에 중복 배정할 수 있습니다.

**⚡스마트 컬렉션.** 조건(검색어·저자·태그·연도 범위·유형)을 저장하면 조건에 맞는 문헌이
자동으로 모입니다. 문헌을 추가·수정하면 소속도 자동으로 바뀝니다.

**복수 선택.** 마우스 드래그, `Ctrl`+클릭(개별), `Shift`+클릭(범위)으로 여러 문헌을
선택한 뒤 우클릭 메뉴에서 일괄 작업(인용·원문 확보·AI 요약·컬렉션 배정·휴지통)을 실행합니다.

**휴지통.** 삭제한 문헌은 휴지통으로 이동하며(항상 확인 팝업), 복원 시 컬렉션 배정까지
되살아납니다. 휴지통에서의 삭제는 영구 삭제입니다.

**미분류.** 어떤 컬렉션에도 속하지 않은 문헌 모음 — 정리 대기열로 쓰세요.

## 4. 인용 삽입과 참고문헌

1. 문서에서 인용할 위치에 **커서**를 둡니다.
2. Ibis에서 문헌을 선택하고(복수 선택 = 병렬 인용) 형태·쪽을 정한 뒤 **인용 삽입**:
   - 괄호형 `(홍길동, 2024)` · 서술형 `홍길동(2024)` · 연도만 `(2024)`
   - 쪽수 입력 시 `(홍길동, 2024, 23)`
3. **참고문헌 갱신** — 문서 끝 새 페이지에 참고문헌 목록이 생성·정렬됩니다.
   서지를 수정했거나 인용을 지웠을 때도 이 버튼 하나로 전체가 다시 맞춰집니다.

세부 동작:
- 인용은 한글 **누름틀**(Word: 콘텐츠 컨트롤)로 들어가므로 일반 텍스트처럼 깨지지 않습니다.
- 나란히 붙은 인용은 갱신 시 자동으로 **병렬 인용** `(김철수, 2026; 황지은, 김동일, 2022)`으로 합쳐집니다.
- 같은 저자·같은 연도 문헌은 `2020a`, `2020b`처럼 접미사가 자동 부여됩니다.
- 참고문헌은 내어쓰기·국문/영문 혼합 정렬·학술지명 강조 등 학회 서식을 따릅니다.

> **원칙 — 단일 출처**: 문서의 인용·참고문헌은 항상 "내 서지" 데이터를 기준으로 갱신됩니다.
> 내 서지에서 오탈자를 고치면 다음 갱신 때 문서의 인용·참고문헌에 그대로 반영됩니다.

### 인용 스타일 맞추기

- **문서별 스타일:** 인용 스타일은 **한글/Word 문서마다 따로 저장**됩니다. 연결 상태에서
  스타일을 바꾸면 그 문서의 본문 인용·참고문헌이 즉시 다시 렌더됩니다.
  지정: ⚙설정 → *인용 스타일*, 또는 사이드바 '문서 연동'의 문서 우클릭 → '인용 스타일 변경'.
- **내장 스타일 3종:** APA 7(저자-연도, 기본값)·Vancouver(번호형)·번호형 [n](본문 [n]/참고문헌 APA).
- **저널 스타일 편집기**(⚙설정 → 인용 스타일 → *저널 스타일 관리…*): 학술지 투고규정을
  프리셋으로 저장합니다. 저자 축약·구분자·쪽 표기·제목 따옴표 등을 폼에서 편집하고
  오른쪽 미리보기로 즉시 확인합니다(내장 프리셋 '교육사회학연구(KJSE)' 포함).
  - **언어×유형 강조 매트릭스:** 유형(학술지·단행본·학위논문·신문·웹 등) × 언어(국문/영문)
    격자에서 제목·수록처 강조를 셀별로(**기본/없음/기울임/볼드/밑줄**) 지정 — 국문 단행본
    밑줄, 영문 이탤릭 같은 국내 학회 관례를 그대로 재현합니다.
  - **원고 세칙 AI 분석:** 학회 투고규정(텍스트·URL·PDF/DOCX/HWPX 파일)을 AI가 읽어
    스타일 파라미터 초안으로 변환해 편집기 폼에 자동으로 채웁니다(AI 제공자 설정 필요, [6절](#6-ai-연구-도우미)).
- **둥근 따옴표 자동 정규화:** 곧은 따옴표(`'` `"`)는 출력 시 문맥에 따라 여닫이 둥근
  따옴표(`‘ ’` · `“ ”`)로 자동 교체됩니다(별도 설정 없음).

## 5. PDF 확보와 원문 열기

- **📥 원문 확보**(문헌별) / **📥 PDF 일괄 확보**(🔧도구): 합법적 무료 공개본(OA)만 순서대로
  탐색합니다 — arXiv → Unpaywall → Semantic Scholar → 랜딩 `citation_pdf_url`·KCI 무료원문.
  결과는 브리핑 팝업으로 요약됩니다.
  - Unpaywall은 이메일을 ⚙설정에 넣으면 활성화되어 확보율이 올라갑니다.
  - 학위논문은 무료 기관 리포지터리(RISS → dCollection)를 따라가 자동 확보·첨부됩니다.
- 확보 실패(구독 DB 논문)는 **🏛 도서관 경유로 열기**를 쓰세요 — ⚙설정에 소속 기관의
  프록시 주소를 넣으면 교외에서도 기관 구독으로 원문 페이지를 **브라우저에 열어줍니다**.
- **직접 받은 PDF는 다운로드 폴더 감시로 올바른 문헌에 자동 첨부**됩니다(애매하면 확인 팝업).
- 첨부가 있는 문헌은 목록에 📎이 표시되고, 상세 패널에서 클릭하면 **앱 안 PDF 뷰어**로 열립니다(PDF가 아닌 첨부는 외부 기본 앱으로).

> **책임 안내** — 자동 확보는 무료 공개본(OA)만 대상으로 하며, 구독 DB 원문을 자동으로
> 내려받지 않습니다. 도서관 경유는 인증 창을 열어 주는 역할까지이며, 이후 열람·다운로드는
> 사용자의 몫입니다. 일부 대학 도서관·DB 제공사는 스크립트·AI 에이전트 등 **자동화 도구를 통한
> 접속을 이용약관으로 제한**하니, 소속 기관의 정책을 확인하고 **본인 책임 하에** 이용하세요.

### 인앱 PDF 뷰어·주석

![인앱 PDF 뷰어 — 하이라이트·밑줄·메모 주석과 주석 모아보기 패널](img/08-pdf-viewer.png)
<sup>첨부 PDF를 앱 안에서 열어 형광펜·밑줄·메모를 달고, 우측 '주석 모아보기'로 한눈에 훑습니다.</sup>

상세 패널의 PDF 첨부를 클릭하면 **앱 안 별도 창(PDF.js)**에서 열립니다 — 확대·스크롤·텍스트 선택/복사가 됩니다.

- **주석 달기:** 텍스트를 드래그한 뒤 **우클릭 메뉴 또는 단축키 `H`(하이라이트)·`U`(밑줄)·`N`(메모)**로 답니다. 형광펜·밑줄 색을 고르고 투명도를 조절할 수 있으며(기본 20%), `Ctrl+Z`로 되돌립니다.
- **자동 저장·복원:** 주석은 첨부 옆 `<파일명>.pdf.annots.json`에 저장되어 다시 열면 그대로 유지됩니다(라이브러리 동기화를 따라감).
- **주석 모아보기:** 하이라이트·밑줄·메모 발췌 목록에서 항목을 클릭하면 해당 위치로 이동하고, 우클릭 삭제·전체 복사가 됩니다.
- **페이지 이동·쪽번호:** 현재/총 페이지 표시·번호 입력 이동, 학술지 인쇄 쪽번호를 자동 인식합니다(안 맞으면 툴바 '시작쪽'으로 보정).
- **주석 포함 인쇄:** 뷰어에서 인쇄하면 하이라이트·밑줄이 반영되고 끝에 주석 모음(메모 포함) 페이지가 붙습니다.

(⚙설정 → AI). 설정하지 않으면 AI 기능은 비활성 상태입니다.

**AI 요약.** 문헌의 AI(별) 아이콘(또는 우클릭 → AI 요약, 복수 선택 = 일괄 요약):
첨부 PDF를 읽고 ① 연구 질문 ② 방법 ③ 핵심 결과 ④ 시사점/한계를 요약해 노트의 **'## AI 요약'
섹션**에 저장하고, **분류 태그**와 **논문 키워드**(서지 정보)를 자동 등록합니다.
BERTopic·LLM 같은 기술 용어는 원어로 표기됩니다.

> 재요약 시 'AI 요약' 섹션과 직전 AI가 넣은 태그·키워드만 갈아끼우고, **사용자가 직접 쓴
> 메모·수동 태그는 보존**합니다. 스캔본(이미지 PDF)은 텍스트가 없어 요약을 건너뜁니다.

![AI 요약 결과 팝업](img/04-ai-summary.png)
<sup>요약·키워드·태그가 한 번에 생성되어 문헌에 저장됩니다.</sup>

**서지정보 AI 채우기.** 상세의 마법봉 아이콘 — DOI가 있으면 권위 소스(Crossref·KCI)를 먼저
조회하고, 빈 항목이 남으면 첨부 PDF 표지를 AI로 분석해 보완합니다.

**🧹 AI 태그 정리**(🔧도구). 태그가 쌓이면 실행하세요 — AI가 제안하고, 적용할 묶음만 체크해서
반영합니다:
- **표기**: 버트토픽, bertopic → `BERTopic` (음차·철자 변형 병합)
- **병기**: LLM, 거대언어모델 → `LLM(거대언어모델)` (번역쌍을 한 태그로)
- **삭제**: `학술논문분석`처럼 필터 가치가 없는 과잉 일반 태그 제거

## 7. 태그 그래프 뷰

좌측 레일의 그래프 아이콘으로 켭니다. **노드 = 태그**(크기 = 문헌 수, 라벨에 개수 표시),
**연결선 = 같은 문헌에 함께 등장**.

![태그 그래프 뷰](img/03-graph.png)

- 노드 **클릭** → 해당 태그의 문헌이 중앙 목록에 표시
- 노드 **드래그**로 재배치(주변이 동적으로 반응), **휠 = 줌**, 빈 공간 **드래그 = 이동**
- 노드 **호버** → 이웃 태그만 하이라이트 · 노드 **우클릭** → 태그 이름 변경·병합/삭제
- **빈 공간 더블클릭 → 별도 그래프 창**(크게 보기) — 그 창에서 노드를 클릭하면 본창 목록이 이동
- 스코프 선택: 전체 서지 / 컬렉션 / ⚡스마트 / 📄문서별
- 태그가 없다면 먼저 AI 요약을 실행하세요 — 태그가 자동 생성됩니다.

![별도 그래프 창](img/07-graph-window.png)
<sup>빈 공간 더블클릭으로 여는 별도 그래프 창 — 노드를 클릭하면 본창 목록이 이동합니다.</sup>

## 8. 서지 편집

문헌 선택 → 상세 패널의 **✏ 버튼**(또는 우클릭 → 서지 편집, 단축키 `F2`):
유형·언어·제목·저자·연도·수록처·권/호/쪽·출판사·DOI·URL·논문 키워드를 수정합니다.

- 저자는 세미콜론으로 구분: `홍길동; Smith, John`
- 첨부·태그·노트·★·추가일은 그대로 보존됩니다.
- **문서에 인용된 문헌이면 저장 즉시 문서의 인용·참고문헌도 함께 갱신**됩니다.

![서지 편집 모달](img/06-edit.png)

## 10. 문서 추적 — 파일명 변경·다른 PC

문서에는 눈에 안 보이는 **문서 식별자(UUID)**가 심어집니다. 그래서:
- 문서 **파일명을 바꿔도** 인용·참고문헌 관리가 이어집니다.
- 라이브러리 폴더를 동기화(OneDrive 등)하면 **다른 PC에서 같은 문서**를 열어도
  이어서 작업할 수 있습니다.
- 사이드바 *문서 연동*에는 지금 열려 있는 문서만 표시되고, 문서를 닫으면 자동으로 사라집니다.

## 11. 데이터·설정과 백업

- **라이브러리(도구 › 라이브러리):** 서지(`library.json`)·첨부 PDF·문서별 인용·저널 스타일이
  라이브러리 폴더에 모입니다 — 이 폴더만 백업하면 됩니다. **새로 만들기 / 열기 / 사본 저장(백업)**으로
  라이브러리를 관리하고, 폴더를 클라우드(OneDrive·Drive·Dropbox)에 두면 여러 PC에서 공유합니다.
- **비밀값은 항상 로컬:** API 키·테마·AI 설정은 라이브러리와 분리된 로컬 설정에 저장되며
  동기화되지 않습니다 — 클라우드 라이브러리를 써도 **PC마다 따로** 넣어야 합니다.
- **테마·항상 위 고정**(⚙설정 → 표시): 테마는 Slate·Ivory·Bright·Graphite 중 선택(선택 즉시
  저장). **항상 위 고정**은 본창을 한글/Word 위에 띄우며 **세션 한정 — 재시작하면 해제**되고
  본창에만 적용됩니다.
- **내보내기(CSL-JSON·BibTeX)**를 주기적으로 받아 두면 이중 백업이 됩니다.
