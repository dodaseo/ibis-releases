# Ibis FAQ

한국 연구자를 위한 서지·인용 관리 앱 **Ibis** 자주 묻는 질문. 기준 버전 **2026.9.1**.

- **국내 학술 검색 → 원문 확보 → AI 분석 → 태그 그래프**까지 한 프로그램에서 끝냅니다.
- 한글(HWP)·Word 본문 인용 삽입(CWYW)도 그중 한 기능입니다.
- 검색·서지 관리·인용 삽입은 **설정 없이 바로** 됩니다. ScienceON·AI 만 선택 설정.

## 시작하기 · 설치 · 환경

**Q. Ibis 는 다른 서지 관리 도구와 뭐가 다른가요?**

- **국내 학술 DB 를 1급으로 지원** — KCI·ScienceON·국립중앙도서관 검색, 국문/영문 병기 보강.
- **원문 확보까지 앱 안에서** — 무료 OA 폭포수 자동 확보, 구독 DB 는 도서관 교외접속 경유로 연결, 학위논문은 RISS→dCollection 자동 추적.
- **읽고 분석하는 것까지** — 인앱 PDF 뷰어·주석, AI 리서치 노트·비판적 검토, 태그 그래프 뷰.
- **한글(HWP) 본문 인용** — EndNote·Zotero·Mendeley 에 없는 기능. 다만 여러 기능 중 하나.
- 데이터는 **로컬 우선**이고 CSL-JSON 으로 열려 있어 특정 DB 에 묶이지 않습니다.

**Q. 설치본(setup.exe)과 zip 중 뭘 받나요?**

- **setup.exe** (권장) — 관리자 권한 불필요, 시작 메뉴·바탕화면 아이콘, 제어판에서 제거.
- ⚠ **`win64.zip` 은 받지 마세요** — **앱이 업데이트할 때 스스로 내려받는 파일**입니다(2026.8.10 부터 안내에서 뺐습니다). 사람이 받아 풀면 자동 업데이트·바로가기·제거가 되지 않습니다.
- 이미 쓰고 있으면 **앱 안에서 자동 업데이트**되므로 따로 받지 않아도 됩니다.

**Q. 설치할 때 'Windows의 PC 보호'(SmartScreen) 경고가 떠요.**

- 정상입니다 — **코드 서명 인증서가 없어서** 나는 경고이고 바이러스와 무관합니다.
- `추가 정보 → 실행` 으로 진행.
- 걱정되면 릴리스의 `.sha256` 과 대조: `Get-FileHash <파일> -Algorithm SHA256`.

**Q. 어디에 설치되나요? 관리자 권한이 필요한가요?**

- 관리자 권한 **없이** `%LOCALAPPDATA%\Programs\Ibis` 에 설치됩니다. **설치 위치는 묻지 않습니다**(2026.8.10 부터).
  - 예전에는 고를 수 있었는데, `C:\Program Files` 를 고르면 인앱 업데이트가 그 폴더를 직접 교체하지 못해 깨졌습니다. 그래서 묻지 않게 했습니다.
- **서재(서지·첨부)는 설치 폴더 밖**에 있어 제거·재설치·업데이트로 지워지지 않습니다 — 아래 '어디에 저장되나요' 참고.

**Q. 설치 마지막 화면의 'AI 연동 설정 열기' 는 뭔가요?**

- 켜면(기본 꺼짐) 설치 후 첫 실행에서 **AI 설정 화면부터** 열립니다. 그뿐이고, 안 켜도 나중에 ⚙설정에서 하면 됩니다.
- 인스톨러가 **AI CLI 를 대신 깔지는 않습니다** — 로그인이 브라우저 인증이라 무인 설치로 끝나지 않기 때문입니다.

**Q. 버전이 `0.7.2` 다음에 `2026.7.1` 이던데 맞나요?**

- 맞습니다. 2026-07 부터 **날짜 기반(CalVer `연.월.패치`)** 으로 바꿨습니다.
- 번호가 아니라 **언제 빌드인지**가 바로 보입니다. 인앱 업데이트는 그대로 동작합니다.

**Q. Mac·리눅스에서도 되나요?**

- 현재는 **Windows 전용**입니다.
- 한글 자동화가 Windows COM(`HWPFrame.HwpObject`) 전용이라 macOS 에서는 **본문 인용 삽입만** 불가능합니다.
- 검색·원문 확보·PDF 뷰어·AI·그래프·서지 관리는 기술적으로 이식 가능해, macOS 판은 검토 중입니다(수요 확인 후).

**Q. 처음 켜니 'Ibis 시작하기' 창이 떴어요. 다 입력해야 하나요?**

- 전부 **선택**입니다. [나중에]로 건너뛰어도 됩니다.
- 안내 항목: ①라이브러리 위치 ②무료 원문 조회용 이메일 ③AI 제공자.
- 학술 DB 항목은 없습니다 — KCI·국립중앙도서관은 설정 없이 바로 검색됩니다.
- 검색·인용 삽입·서지 관리는 설정 없이 됩니다. 건너뛴 항목은 ⚙설정에서 언제든.

**Q. API 키 없이 쓸 수 있나요?**

- 됩니다. 검색·인용 삽입·서지 관리 모두 키 불필요.
- **무키 소스**: KCI · 국립중앙도서관 · Crossref · OpenAlex · Semantic Scholar · arXiv · ERIC — 8종 중 7종.
- **키 필요**: ScienceON 하나뿐입니다.
- KCI·국립중앙도서관은 **앱 내장 키**로 동작해 ⚙설정에 입력 칸 자체가 없습니다.

**Q. 데이터와 API 키는 어디에 저장되나요? 클라우드에 올라가나요?**

**두 자리로 나뉩니다.**

- **서재(서지·첨부)** — 새로 설치하면 **`문서\Ibis`**(2026.8.10 부터). 눈에 보이고 백업 도구가 챙기는 자리로 옮겼습니다.
  - 🚨 **쓰고 계시던 분의 서재는 옮기지 않습니다** — 예전 자리(`%LOCALAPPDATA%\Ibis`)를 그대로 씁니다. 기본값이 바뀌었다고 조용히 다른 곳을 보면 서지가 사라진 것처럼 보이기 때문입니다. 내 서재가 어디인지는 `⚙설정 › 라이브러리` 에서 확인하고, 옮기려면 거기 [폴더 변경]을 씁니다.
  - 담기는 것: `library.json` 서지 · `attachments\` 첨부 PDF · `docstore\` 문서별 인용 · `journal_styles\` 저널 스타일.
- **이 PC 전용** — `%LOCALAPPDATA%\Ibis` 에 `secrets.json`(API 키·AI 설정·테마·글꼴)과 검색 색인(`.db`).
  - **`secrets.json` 은 항상 로컬 전용** — 어떤 동기화에도 실리지 않습니다. 그래서 PC 마다 따로 넣습니다.
- 서재만 클라우드 폴더로 옮길 수 있고, 이때 서지·첨부·docstore·저널 스타일이 함께 이동합니다(계정 기반 동기화는 '내 서재 동기화' 를 보세요).

**Q. `library.json` 과 SQLite(`.db`) 중 진짜 데이터는?**

- **`library.json` 이 권위(원본)** 이고 클라우드 동기화 대상.
- `.db` 는 검색 색인용 로컬 프로젝션 — 지워도 `library.json` 에서 재생성됩니다.
- 문제 시 환경변수 `IBIS_BACKEND=file` 로 파일 백엔드 복귀(옛 이름 `HWPENDNOTE_BACKEND` 도 그대로 인정됩니다. 라이브러리 위치는 `IBIS_LIBRARY` / 옛 `HWPENDNOTE_LIBRARY`).

## 문서 연동 (CWYW)

**Q. '독립 모드'가 뭔가요?**

- 한글·Word 에 연결하지 않은 상태.
- 검색·원문 확보·AI·그래프·서지 관리 전부 동작하고, **문서에 인용을 꽂는 기능만** 막힙니다.
- 연결하려면 상단 상태 배지를 클릭.

**Q. 배지를 눌러도 반응이 없어요.**

- Ibis 는 워드프로세서를 **대신 실행하지 않고 이미 열린 앱에만 붙습니다.**
- 한글/Word 에서 문서를 먼저 연 뒤 배지를 누르세요.
- 둘 다 켜져 있으면 '연결할 앱 선택' 메뉴가 먼저 뜹니다.
- 연결 후 다른 문서를 열었다면 `🔄 목록 새로고침`.

**Q. 한글 보안 모듈 팝업이 뜨나요?**

- 정상적으로는 뜨지 않습니다 — pyhwpx `register_module=True` 로 자동 등록.
- 환경에 따라 뜨면 한 번 허용하면 이후로는 나오지 않습니다.
- 참고문헌 재구축 중 '누름틀 삭제' 확인 팝업은 앱이 자동 응답 후 원복합니다.

**Q. 한글과 Word 의 기능 차이는?**

- 공통: 인용 삽입 · 병렬 병합 · 전체 재서식 · 참고문헌 재구축(새 페이지·내어쓰기·강조).
- **한글에만**: 인접 인용 자동 병합((a)(b) → (a; b)) — 간격을 필드 위치로 계산하기 때문.

**Q. 인용 형태와 쪽수는 어디서?**

- 문헌 선택 → 우측 상세 패널의 형태 드롭다운 + '쪽' 칸 → [인용 삽입].
- **형태 5종**: 괄호형 `(홍길동, 2024)` · 서술형 `홍길동(2024)` · 연도만 `(2024)` · **서지에만 표시**(본문에 안 보이고 참고문헌에만) · **표기 생략 — 쪽만** `(23)`.
- **서술형은 복수 문헌도 됩니다** — `Apple (2013), Aranda (2021)`. 다만 **'연도만' 은 복수 문헌에 쓸 수 없습니다**(어느 문헌의 연도인지 알 수 없어 차단됩니다).
- 삽입한 뒤에도 **인용 편집 창**에서 형태·쪽을 바꿀 수 있습니다.

**Q. 인용 여러 개를 한 괄호로 묶으려면?**

- 목록에서 여러 건 선택 → 우클릭 `⤵ 인용 삽입` → 병렬 인용((a; b)).
- 또는 기존 인용 괄호 안에 커서를 두고 다른 문헌을 인용 → 합쳐집니다.
- 붙여 쓴 별개 인용은 전체 갱신 때 한글에서 자동 병합.

**Q. 2020a, 2020b 접미사가 붙어요.**

- 정상 — APA 규칙. 저자 표기·연도가 같은 그룹을 **제목 사전순**으로 a/b/c 부여.
- 본문 인용과 참고문헌에 일관 적용. 공저자 구성이 달라 이미 구별되면 붙이지 않음.
- 연도 미상은 `n.d.-a` 형태.

**Q. 내 서지에서 고치면 문서에도 반영되나요?**

- 네 — 인용·참고문헌은 항상 **내 서지(master) 기준**으로 렌더됩니다.
- 수정 후 `참고문헌 갱신` 실행. 문서에만 있던 문헌은 내 서지로 자동 승격.

**Q. 문서 파일(.hwp)만 동료에게 보냈더니 인용 정보가 없다고 나와요.**

- 인용 데이터는 문서가 아니라 **라이브러리의 `docstore/<uuid>.json`** 에 있습니다(문서에는 안 보이는 UUID 만 심음).
- 받는 쪽에는 그 기록이 없어 문서에 남은 필드가 '유령 인용(orphan)'으로 보고됩니다.
- 함께 작업하려면 라이브러리 폴더(또는 해당 docstore json)를 공유하거나 공용 클라우드 폴더 사용.

**Q. 문서명을 바꾸거나 다른 PC 로 옮기면?**

- 안전합니다 — 문서마다 안 보이는 고유 ID(한글=숨김 필드, Word=문서 변수)를 심습니다.
- 라이브러리를 클라우드에 두면 다른 PC 에서 이어 작업 가능.

**Q. 논문마다 다른 저널 스타일을 쓸 수 있나요?**

- 네 — 스타일은 **문서마다** 저장됩니다.
- 문서에 연결한 상태에서 바꾸면 그 문서의 기존 인용·참고문헌이 즉시 재렌더.
- 사이드바 '문서 연동' 의 문서 우클릭 › '인용 스타일' 에서 지정.
- 미연결 상태에서 바꾸면 앱 전체 기본만 변경.

**Q. 문서를 여니 '참고문헌을 새 방식으로 옮깁니다' 라는 안내가 떠요. (2026.8.2)**

- 정상입니다. 참고문헌이 **테두리 없는 한 칸짜리 표** 안으로 들어가는 구조 변경이고, **문서마다 한 번만** 일어납니다.
- 겉모양은 달라지지 않습니다 — 화면·인쇄 모두 예전과 같은 문단으로 보이고 여러 쪽에 걸쳐 이어집니다.
- **옮기기 전에 `.hwp` 파일 백업을 만듭니다.** 그래서 문서가 **저장돼 있어야** 이행됩니다 — 안내가 뜨면 먼저 저장하세요.
- 왜 바꿨나: 종전 방식(표시로 구간을 잡아 지우고 다시 쓰기)은 **원고 본문까지 지울 수 있는 경로**가 있었고 실제로 사고가 났습니다. 이제 경계를 한글이 지키므로 그 경로 자체가 없습니다.

**Q. '참고문헌 구간을 확인할 수 없습니다' 라며 이행하지 않아요.**

- 그 구간이 앱이 쓴 그대로가 아니라는 뜻입니다(손으로 고쳤거나 다른 편집이 섞인 경우).
- **아무것도 지우지 않습니다.** 안내에 나온 대로 참고문헌 **글자만** 지우고 갱신하시면, 남은 표시는 앱이 정리하고 새 방식으로 다시 만듭니다.
- 지우기 전에 문서 사본을 하나 두시면 마음이 편합니다.

**Q. 인용을 손으로 고쳤는데 갱신하면 날아가나요? (2026.8.2)**

- 아닙니다 — 갱신 전에 **묻습니다**. '유지'(손으로 쓴 표기를 지키고 이후 갱신에서 제외) 또는 '정식 표기로 되돌리기' 중에 고릅니다.
- 제외해 둔 인용은 **인용 편집 창의 [적용]** 으로 언제든 다시 갱신 대상으로 되돌립니다.
- 종전에는 경고 없이 덮어써졌습니다.

**Q. 인용이 문서 어디에 있는지 찾기 어려워요. (2026.8.2)**

- 레일의 **인용 아이콘(❝)** 으로 **인용 편집 창**을 엽니다 — 문서의 인용이 **나오는 순서대로** 전부 보입니다.
- **행을 클릭하면 한글이 그 자리로 이동**합니다. ✎(더블클릭·우클릭)로 표기 방식·쪽·병렬 구성 문헌을 그 자리에서 고칩니다.
- '갱신하면 표기가 달라질 인용'에는 배지가 붙어, 무엇이 바뀔지 미리 보고 갱신할 수 있습니다.

**Q. 본문에는 안 나오고 참고문헌에만 올리고 싶어요. (2026.8.2)**

- 인용 형태에서 **'서지에만 표시'** 를 고릅니다.
- 같은 문헌을 이어 인용하며 쪽만 바꿀 때는 **'표기 생략 — 쪽만'**(`(23)`)을 씁니다.
- 이로써 괄호형·서술형·연도만과 함께 **형태 5종**이 됩니다.

**Q. 문서에서 인용을 지웠는데 참고문헌에 남아요.**

- 문서를 다시 연결하거나 `참고문헌 갱신` 실행 → 실제 문서 필드와 대조해 자동 정리.

**Q. 참고문헌 제목('참고문헌')이 안 나와요.**

- 기본값이 **제목 없음**입니다.
- 참고문헌은 항상 새 페이지에서 시작하며, 제목은 저널 스타일의 `bib_heading` 을 지정할 때만.
- 목록은 테두리 없는 표 안에 들어가지만 겉모양은 일반 문단과 같습니다(위 이행 안내 참고).
- 각 항목은 APA 0.5in 내어쓰기 + 스타일별 강조(이탤릭/볼드/밑줄).

## 검색 · 수집

**Q. 무엇을 찾아야 할지부터 막막할 때는요? (2026.9.1)**

- 레일 **세 번째 아이콘 [질문으로 찾기]** — 낱말이 아니라 **연구 질의를 문장으로** 던지면 국내외 DB 와 내 서재를 한 번에 뒤져 **관련도 순위**로 보여 줍니다.
- 검색 대상을 고릅니다: `전체` │ `내 서재` │ 국내(KCI·ScienceON·국립중앙도서관) │ 국외(OpenAlex·Crossref·ERIC·arXiv).
- **검색어는 AI 가 국문·영문 조합으로 만들고**, 모은 것(통상 200여 건)을 **전부 채점**해 100여 편을 보여 줍니다.
- 국립중앙도서관 **단행본도 순위에 오릅니다** — 책소개가 없으면 카카오 책·알라딘에서 입혀 채점합니다.
- **치른 크레딧이 아깝지 않게** — [최근 질의] 에서 누르면 **크레딧 0** 으로 결과가 되살아납니다.
- 낱말로 좁혀 찾는 것은 여전히 **외부 검색**입니다. 둘은 쓰임이 다릅니다.

**Q. 어떤 검색 소스를 쓸 수 있나요?**

- **8종** — 국내: KCI · ScienceON · 국립중앙도서관 / 해외: OpenAlex · Crossref · ERIC · arXiv · Semantic Scholar.
- **'국내 통합'·'해외 통합'** — 각 묶음을 병렬 질의 후 중복 병합.
- ERIC 은 미국 교육부 IES 가 운영하는 교육학 DB(저널논문·문서/보고서), 키 불필요.
- ScienceON 을 뺀 7종은 설치 직후부터 바로 보입니다.

**Q. 국립중앙도서관은 어떤 자료를 찾나요?**

- **학위논문·도서·연속간행물·웹자료** 등 국내 발행물. 학술논문은 KCI 쪽입니다.
- 유형을 안 고르면 네 갈래를 병렬로 훑습니다.
- 학위논문은 **최신까지** 나옵니다(소장자료 색인 기반). 정렬을 안 골라도 최신부터 보여 줍니다.
- ⚠ **'단행본'·'보고서' 유형은 그 갈래의 일부만** 찾습니다 — 자료구분을 한 번에 하나만 보낼 수 있어 단행본=일반도서만, 보고서=정부간행물만 조회됩니다(아동도서·교과서·공공간행물 등은 빠짐). 앱이 결과줄에 매번 밝힙니다.

**Q. ScienceON 이 드롭다운에 안 보여요.**

- ScienceON 만 사용자 인증키가 필요해, 설정돼 있을 때만 표시됩니다.
- scienceon.kisti.re.kr › 인증키 발급 신청 → **Client ID·인증키·등록 MAC 3개 모두** 입력(하나라도 빠지면 비활성). (helpdesk@kisti.re.kr · 080-969-4114)
- ⚠ 발급 시 **등록한 공인 IP 에서만** 동작합니다 — 다른 네트워크로 옮기면 실패합니다.
- 없어도 앱은 온전합니다. KCI·국립중앙도서관을 포함한 나머지 7종은 키 없이 됩니다.

**Q. 사람 이름으로 검색했는데 0건이 나와요.**

- 예전 이야기입니다 — 검색창에 그냥 친 말은 이제 KCI 를 **제목·저자·키워드 세 갈래**로 나눠 물어 합칩니다.
- 대신 이 합집합 검색은 **약 540건**에서 끝납니다. 더 깊이 넘겨 봐야 하면 필드를 지정하세요(상위 10,000건까지).

**Q. DOI 만 있는 논문을 빠르게 추가하려면?**

- 상단 검색창에 DOI(또는 doi.org 링크) 붙여넣기 → 소스와 무관하게 1건 즉시 해석.
- 또는 ⚙설정의 'DOI로 추가' 칸 → 바로 내 서지에 보관.
- doi.org content negotiation 사용 — 등록기관 무관, 키 불필요.

**Q. 통합 검색에서 한 소스가 실패하면?**

- 나머지는 계속 진행되고, 결과 제목줄에 실패한 소스명이 표시됩니다.
- 중복 병합 기준: **DOI 우선**, 없으면 정규화 제목+연도.

**Q. 검색 결과가 20건에서 안 늘어나요.**

- 외부 소스는 페이지당 20건 — 하단 페이지 바(‹ 1 2 3 … ›)로 이동.
- 페이지를 넘겨도 이전 결과는 인용 대상으로 유지.
- 열람 상한: 국립중앙도서관은 한 갈래마다 500건(유형 미지정이면 합쳐 최대 2,000건), KCI 는 10,000건, 합집합 검색은 1,000건.
- '내 서지' 검색은 전체를 한 번에 보여줘 페이지 바가 없습니다.

**Q. 목록 머리의 '총 465건' 은 뭔가요? 어떤 검색은 왜 안 적히나요?**

- `20건 (총 465건)` — 지금 보이는 건수와 그 검색의 전체 건수입니다.
- **총건수를 알려주지 않는 소스**(Crossref·OpenAlex·Semantic Scholar·arXiv·ERIC)는 숫자를 **아예 적지 않습니다** — 0 으로 채우면 진짜 0건과 구분되지 않기 때문입니다.

**Q. 조건을 여러 개 걸어 검색하려면? (고급검색)**

- `[그리고/또는] [필드] [포함/정확히 이 구] [값]` 조건 줄을 ＋로 쌓습니다(한 묶음 8줄, 「또는」 묶음 3개까지). **「그리고」가 먼저 묶입니다.**
- 필드 그룹: **공통**(전체·제목·저자·발행처·학술지·키워드) / **KCI 전용**(DOI·저자 소속기관·발행기관) / **국립중앙도서관 전용**(ISBN·ISSN·분류기호·자료구분·수록연도) / **내 서지 전용**(초록·첨부파일명).
- 전용 필드를 고르면 **소스가 따라 바뀝니다.**
- 고급검색을 열면 검색창의 글자가 첫 조건 줄로 옮겨 갑니다(닫으면 되돌림).
- 다중 조건을 못 받는 소스: ScienceON 과 해외 소스 전부.

**Q. 고급검색에 초록 검색과 제외(NOT)가 없어요.**

- 일부러 뺐습니다 — KCI 는 초록 조건을 받는 척하고 **버리고**, 국립중앙도서관 응답에는 초록 필드 자체가 없습니다. 있는 척하면 조건이 걸린 줄 알고 잘못 믿게 됩니다.
- 초록 검색은 **'내 서지'** 에서만 됩니다.

**Q. 국내 논문인데 영문 제목·저자만 나와요.**

- 일부 저널이 영문 서지만 제공합니다.
- 저장 시 DOI 가 있으면 **KCI 로 국문 제목·학술지·한글 저자를 보강**하고, 영문은 병기 필드(`title_en`·`container_en`·`authors_en`)로 보존.
- 그래도 비면 상세 패널에서 직접 수정.

**Q. 내 서지 검색은 어디까지 훑나요?**

- 제목·저자·수록처·태그·키워드·AI 요약(노트)·초록·영문 병기 + **첨부 파일명**까지 전문검색(FTS5).
- 검색어 3자 미만이면 제목·수록처만 보는 단순 매칭으로 폴백.
- 고급 검색에서 필드를 좁히면 그 필드만 봅니다.

**Q. EndNote(.enw)·RefWorks·엑셀 표도 가져올 수 있나요?**

- 가져오기 **6형식**: RIS · BibTeX · CSL · EndNote(.enw) · RefWorks · Tab(.tsv/.csv).
- 파일 대화상자 기본 필터는 RIS·BibTeX·CSL — '모든 파일' 로 바꾸면 나머지도 처리.
- '＋추가' 창의 붙여넣기 상자는 6형식 **자동 인식**(끌어놓기 가능).
- **내보내기는 CSL-JSON(.json)·BibTeX(.bib) 2종만**.

**Q. 붙여넣은 인용문이 엉뚱한 논문으로 채워지지 않나요?**

- Crossref '서지 매칭' 을 **쓰지 않습니다**(무관한 논문이 채워지는 것을 막기 위해).
- 본문에 DOI 가 있으면 그것만 해석, 없으면 텍스트에서 저자·연도·제목·수록처·권호쪽을 분해.
- 인식 실패 시 값을 채우지 않고 빈 양식 유지 → 직접 입력.

## 서지 관리 · 컬렉션 · 태그

**Q. 여러 PC(집·연구실)에서 같은 라이브러리를 쓰려면?**

- 라이브러리 폴더를 클라우드 폴더(OneDrive·Drive·Dropbox·NAS)로 지정.
- 한 PC: `⚙설정 › 라이브러리` › '폴더 변경' (또는 온보딩 1단계).
- 다른 PC: `⚙설정 › 라이브러리` › '열기' 로 같은 폴더의 `library.json` 에 연결.
- 함께 동기화: 컬렉션 · 태그 · 첨부 PDF · docstore · 저널 스타일.
- **동기화 안 됨(PC 별 로컬)**: API 키 · AI 설정 · 테마 · 글꼴.
- 🆕 **[내 서재 동기화 (여러 PC)]** 를 함께 켜면 더 든든합니다(⚙설정 › 클라우드, 베타). 같은 구글 계정의 다른 PC 와 **서재 전체**(개인 메모·즐겨찾기 포함)를 서버로 맞춥니다 — 폴더 동기화만으로는 같은 서지를 양쪽에서 고쳤을 때 충돌본이 생기는데, 그 부분을 서버가 칸 단위로 정리합니다. **PDF 파일은 여전히 폴더 쪽 몫**이라 둘을 함께 켜는 것이 권장 구성입니다.

**Q. '새로 만들기'·'열기'·'사본 저장' 차이는?**

- **새로 만들기** — 빈 폴더에 새 라이브러리 생성 후 전환(이미 있으면 오류).
- **열기** — 기존 라이브러리에 복사 없이 연결·전환(없으면 오류). 다른 PC 의 클라우드 라이브러리에 붙을 때.
- **사본 저장(백업)** — 다른 폴더로 복사만, 전환하지 않음.
- 앞의 둘은 전환 전에 현재 라이브러리를 자동 저장합니다.

**Q. 컬렉션과 스마트 컬렉션의 차이는?**

- **컬렉션** — 직접 드래그해 넣는 수동 폴더(계층·색 지정).
- **스마트 컬렉션** — 조건(검색어·저자·태그·연도·유형)을 저장해 자동으로 모이는 동적 묶음.
- 문헌을 추가·수정하면 스마트 쪽은 자동 갱신, 일반 컬렉션은 직접 관리.

**Q. 태그는 어디서 걸러 보나요?**

- 별도 태그 사이드바는 없습니다 — 레일의 그래프 아이콘 → **태그 그래프 뷰**.
- 태그 노드 클릭 → 그 태그의 문헌이 중앙 목록에.
- 상단 스코프(전체/컬렉션/스마트/문서)로 범위 조절.

**Q. 그래프에 태그가 하나도 안 나와요.**

- 노드는 태그이므로 문헌에 태그가 있어야 보입니다.
- 상세 패널에서 직접 입력하거나, 우클릭 › 'AI 요약' 으로 자동 생성(AI 설정 필요).
- 스코프가 좁혀져 있으면 비어 보일 수 있으니 '전체 서지' 로 확인.

**Q. 태그가 'BERTopic' 과 '버트토픽' 으로 갈라졌어요.**

- 그래프에서 태그 노드 우클릭 › '이름 변경·병합'.
- 여러 개를 한 번에: `도구` › 'AI 태그 정리…' — AI 가 음차·번역·띄어쓰기 차이의 병합안을 제안하고 **적용할 묶음만 골라** 반영(AI 는 제안만).

**Q. 같은 주제 컬렉션을 여러 번 만들어 나뉘었어요.**

- 사이드바에서 **Ctrl+클릭**(범위는 Shift+클릭)으로 둘 이상 고르고 우클릭 › **[컬렉션 합치기]** → 어느 것을 남길지 고릅니다(2026.8.10).
- **문헌은 지워지지 않습니다** — 컬렉션 구성만 바뀌고 양쪽에 있던 문헌은 한 번만 남습니다.
- 없어지는 컬렉션의 **하위·스마트 컬렉션은 남는 컬렉션 밑으로** 갑니다.
- ⚠ **클라우드로 공유 중인 컬렉션은 없어지는 쪽이 될 수 없습니다** — 서재에서 사라지면 동료와의 공유가 끊기기 때문입니다.

**Q. 실수로 삭제한 문헌을 되살릴 수 있나요?**

- 삭제는 휴지통으로 이동 — '휴지통' 뷰에서 우클릭 › '복원'(컬렉션 소속까지 복구).
- '영구 삭제' 만 되돌릴 수 없습니다.

**Q. 중복 논문을 한 번에 정리하려면?**

- `도구` › '중복 문헌 정리'(확인창에서 승인) — DOI 또는 정규화 제목+연도가 같은 문헌을 **정보가 가장 충실한 1건**에 병합.
- 자동 처리: 빈 필드 보강 · 첨부/키워드 합침 · 컬렉션 이관 · ★·이른 추가일 승계.

**Q. 검색으로 안 나오는 국역서·법령을 넣고 싶어요.**

- 상단 '＋추가' → 인용문이나 DB 내보내기 파일을 붙여넣고 '파싱하여 추가'.
- 없으면 유형(단행본·법령·조례 등)을 골라 직접 입력 → 인용키 자동 생성.

**Q. 컬렉션을 동료와 나누고 싶어요.**

- 두 방식이 있고 **병행**합니다 — 파일은 *한 번 건네는 것*, 클라우드는 *계속 맞춰 가는 것*입니다.
- **파일** — 컬렉션 우클릭 › [공유 파일로 내보내기 (.ibiscol)…] → 메일·USB 로 전달 → 받는 쪽은 [공유 컬렉션 가져오기 (.ibiscol)…]. 서버를 안 거치고 오프라인에서도 됩니다.
- **클라우드(베타)** — ⚙설정 › 클라우드에서 구글 로그인 → 컬렉션 우클릭 › [클라우드로 공유…] → [초대…] 에 상대 이메일. 서지를 고치면 저절로 맞춰집니다.

**Q. 공유하면 내 PDF 와 메모까지 넘어가나요?**

- **PDF 원문 파일은 나가지 않습니다**(저작권 — 받는 쪽이 자기 도서관 계정으로 확보합니다). **개인 메모와 즐겨찾기도 나가지 않습니다.**
- 나가는 것: 서지 · 컬렉션 구성 · **하이라이트와 메모** · Ibis 가 만든 AI 요약 섹션.
- 하이라이트는 파일이 아니라 **위치와 문장**으로 갑니다. 받는 쪽이 그 원문을 확보해 열면 **판본이 달라 쪽수가 어긋나도** 문장으로 다시 찾아 붙습니다.
- 클라우드는 **초록도 올리지 않습니다**(용량).
- ⚠ 이것은 **남에게 건넬 때**의 규칙입니다. 직접 켜는 **[내 서재 동기화 (여러 PC)]** 는 받는 쪽이 같은 계정의 나 자신뿐이라 **개인 메모·즐겨찾기·초록도 함께** 올라가고, 남에게는 나눌 수 없습니다(서버가 초대를 거절합니다). **PDF 원문은 거기서도 올라가지 않습니다.**

**Q. 클라우드 공유에 가입해야 하나요? 무엇을 받아 가나요?**

- 별도 가입은 없습니다 — **구글 로그인 하나**로 끝입니다.
- 받는 개인정보는 **이메일 주소 1개**(참가자 식별·초대용)뿐입니다. 로그인 창의 **[개인정보 처리방침 보기]** 로 로그인 전에 확인하실 수 있습니다.
- 베타 할당은 **1인 5MB** 이고, 상태줄에 `☁ 사용량 / 5MB` 로 늘 보입니다(서지·주석 기준으로 약 2,000건). 상한에 닿으면 올리기가 거절되고 그 사실을 알립니다.

**Q. 내 서재 전체를 여러 PC 에서 맞출 수 있나요?**

- 네 — `⚙설정 › 클라우드` › **[내 서재 동기화 (여러 PC)]** (베타). 같은 구글 계정으로 로그인한 내 다른 PC 와 **서재 전체**를 맞춥니다.
- 컬렉션 공유와 달리 **개인 메모·즐겨찾기·초록도 함께** 갑니다(받는 쪽이 나 자신이므로). **남과는 나눌 수 없습니다** — 서버가 초대를 거절합니다.
- 다른 PC 에서 이미 켰다면 **그것을 먼저 받아 합칩니다.** 한쪽에서 지운 문헌·컬렉션은 다른 PC 에서도 정리됩니다(문헌은 휴지통으로, 컬렉션이 없어져도 그 안의 문헌은 서재에 남습니다).
- **PDF 원문 파일은 올라가지 않습니다.** 파일까지 맞추려면 라이브러리 폴더를 클라우드 폴더에 두는 방식을 **함께** 쓰세요(권장 구성).
- 끄기는 기본이 이 PC 연결만 끊기이고, 원하면 서버 사본까지 지울 수 있습니다.

**Q. 클라우드로 함께 고치는데 상대가 고친 값이 안 보여요.**

- **서지 교정은 칸 단위로 오갑니다**(2026.8.8 부터). 지난 동기화와 견주어 **내가 손대지 않은 칸**을 동료가 고쳤으면 받아 오고, **내가 고친 칸**은 지킵니다. 서로 다른 칸을 고친 것은 둘 다 삽니다.
- **같은 칸을 둘이 다르게 고친 경우에만** 나중 것으로 맞추고, **무엇이 덮였는지 동기화 결과에 알립니다.** 다만 시각 비교가 문헌 단위라 **같은 날 안에서의 앞뒤는 못 가립니다** — 중요한 교정은 서로 알려 주세요.
- **컬렉션의 이름·색·정렬 순서를 바꾼 것은 전파되지 않습니다**(베타 한계) — 참가자마다 다르게 굳는 것을 막으려고 일부러 뺐습니다. 문헌을 넣고 빼는 것은 정상으로 오갑니다.

**Q. 공유를 그만두려면?**

- 컬렉션 우클릭 › **[클라우드 공유 해제…]**. **소유자**는 *서버에서 없애기* 와 *이 PC 연결만 끊기* 중에 고릅니다.
- **참가자**는 **[공유에서 나가기]** 입니다.
- 누가 들어와 있는지와 나간 초대 링크는 우클릭 **[참가자·초대 관리…]** 에서 보고 끊습니다.

**Q. 목록 정렬은?**

- 컬럼 헤더(저자·연도·제목·수록처·유형) 클릭 → 정렬, 다시 클릭 → 오름/내림 토글(▲▼ 표시).
- 연도는 기본 내림차순, 텍스트 컬럼은 기본 오름차순.
- 헤더 경계를 드래그하면 폭 조절, 더블클릭하면 기본 폭 복원.

## 인용 스타일

**Q. 내장 스타일은?**

- 엔진 **3종** — **APA 7**(저자-연도, 국문 가나다 먼저 → 서양 알파벳) · **Vancouver**(번호형 [n], 등장순) · **번호형 [n]**(본문 [n] + APA 형식 참고문헌).
- 내장 **저널 스타일 2종** — `APA 6판` · `교육사회학연구`.
- 기본값 APA 7. 엔진 3종은 저널 스타일의 '부모 엔진' 후보이기도 합니다.

**Q. 새 학술지 스타일을 추가하려면?**

- ⚙설정 › 인용 스타일 › '저널 스타일 관리…' › `＋ 새 저널 스타일`.
- 부모 엔진 + 파라미터(저자 축약·구분자·제목 따옴표·유형×언어 강조·DOI 등) 지정.
- 또는 '원고 세칙 AI 분석' 으로 투고규정을 붙여넣어 초안 자동 생성 후 확인·수정.

**Q. 만든 스타일을 다른 PC·동료와 공유하려면?**

- 라이브러리 폴더의 `journal_styles/<id>.json` 파일입니다.
- 라이브러리를 클라우드에 두면 자동 동기화, 파일만 복사해 전달해도 됩니다.

**Q. 내장 스타일을 고칠 수 있나요?**

- 내장 스타일 자체는 삭제 불가.
- 편집기에서 **같은 이름으로 저장**하면 같은 id 의 '사용자 판' 이 우선 적용.
- 사용자 판을 삭제하면 내장 스타일 복원.

**Q. Vancouver 부모 저널 스타일에서 저자 축약·강조 설정이 먹나요?**

- **먹습니다** — 2026.8.1 에서 고쳤습니다(그 전에는 밴쿠버가 편집기 파라미터를 무시했습니다). 저자 축약·강조·DOI 표기·쪽 표기 모두 반영됩니다.
- 다만 밴쿠버 **자체 기본값**(저자 7인 이상이면 6인 + et al., 무강조)이 있고, 저널 스타일이 **명시한 항목만** 그 위를 덮습니다.
- 본문 표기는 [n] 고정입니다(번호형 엔진도 마찬가지).

**Q. 밴쿠버에서 쪽수를 함께 인용하면?**

- `[1](p23)` 로 나옵니다. 종전 `[1, 23]` 은 "1번과 23번 문헌"으로 읽혀 고쳤습니다.

**Q. 밴쿠버 참고문헌에서 단행본·학위논문에 발행처가 빠져요.**

- 고쳤습니다 — **단행본·보고서는 발행처**, **학위논문은 수여기관**이 찍힙니다.
- ⚠ 이미 밴쿠버로 뽑아 둔 목록이 있다면 갱신 시 그 줄이 달라집니다.

**Q. 갱신했더니 2020a·2020b 순서와 접미사가 바뀌었어요.**

- 같은 저자·같은 해의 `a`/`b` 를 참고문헌에서 **제목순**으로 바로잡았습니다(APA 7판 §9.47).
- 기존 문서를 '전체 갱신' 하면 그 부분의 순서·접미사가 **한 번 바뀝니다.** 이후로는 그대로 유지됩니다.

**Q. 국문 제목만 따옴표를 붙이는 규정도 되나요?**

- 됩니다 — '논문 제목 따옴표' 에서 국문·영문을 각각 지정(예: 국문 「 」, 영문 없음).
- 강조도 '유형×언어' 매트릭스로 분리 지정(국문 단행본 밑줄 · 영문 단행본 이탤릭 등).

**Q. 참고문헌 DOI 표기를 끄려면?**

- 저널 스타일 편집기 › 'DOI 표기' 체크박스(기본 켜짐, 내장 '교육사회학연구' 는 미표기).
- DOI 가 없고 URL 이 있으면 URL 로 대체 표기.

**Q. 곧은 따옴표가 둥근 따옴표로 바뀌어요.**

- 정상 — 출력 시 문맥에 맞춰 여닫이(' ' · " ")로 자동 정규화. 아포스트로피는 오른작은따옴표.
- 별도 설정 항목 없음.

**Q. 원고 세칙 AI 분석에 필요한 것은?**

- ⚙설정의 AI 제공자(구독 CLI 또는 API 키).
- 입력 형식: 텍스트 붙여넣기 · URL · 파일(PDF/DOCX/HWPX).
- 규정에 **명시된 항목만** 파라미터로 변환합니다.
- 레거시 `.hwp` 는 자동 추출이 어려워 한글에서 열어 본문을 복사하는 편이 확실합니다.

**Q. 미리보기에 한글 실행이 필요한가요?**

- 아니요 — 내장 샘플 문헌으로 계산해 렌더하므로 한글 실행·문서 연결 없이 즉시 확인됩니다.

**Q. 문헌 상세의 '스타일 미리보기' 가 실제 문서와 다르게 보여요.**

- 지금은 **같습니다** — 문서에 들어가는 것과 같은 결과를 보여 줍니다.
- 종전에는 어떤 스타일을 골라도 미리보기만 APA 로 보였습니다.

## 원문(PDF) 확보 · 뷰어

**Q. 원문이 자동으로 안 받아져요.**

- 무료 공개(OA) 경로에 없거나 구독 DB 전용인 경우입니다.
- 자동 확보 순서: arXiv → Unpaywall → Semantic Scholar → 랜딩 메타(`citation_pdf_url`) → KCI 무료원문.
- ⚙설정에 **이메일을 넣으면 Unpaywall 이 켜져** 확보율이 오릅니다.

**Q. 구독 DB(DBpia·KISS 등) 원문을 자동으로 받아주나요?**

- **아니요** — 약관·기관 정책상 자동 로그인·클릭·다운로드는 하지 않습니다(준법).
- 앱은 도서관 교외접속 경유로 **원문 페이지를 브라우저에 열어주기만** 합니다.
- 직접 받은 PDF 는 다운로드 폴더 감시로 자동 첨부됩니다.

**Q. 도서관 교외접속(프록시)은 어떻게 설정하나요?**

- ⚙설정 › 검색·원문 › '도서관 경유 URL' + '도서관 홈페이지'.
- 형식은 **자동 인식**됩니다 — 교외에서 DB 를 눌렀을 때 나온 주소를 그대로 붙여넣으면 템플릿으로 변환.
  - 경로형 예: `https://proxy.○○.ac.kr/_Lib_Proxy_Url/` → `{urlraw}`
  - 쿼리형 예: `https://proxy.○○.ac.kr/login?url=` → `{url}`
- ⚠ **호스트가 이미 치환된 주소**(`https://www-sciencedirect-com.proxy.○○.ac.kr/…`)는 붙여넣지 마세요 — 리다이렉트 **결과**라 템플릿이 되지 못합니다. 도서관 DB 목록에서 **링크 주소 복사**로 원본을 얻으세요.
- 프록시는 미로그인 시 접근을 튕기므로 **'로그인 열기' 로 먼저 한 번 로그인**해 세션을 만드세요.
- KCI 무료 원문은 로그인 없이 자동 확보됩니다.

**Q. 여러 논문의 원문을 한꺼번에 받으려면?**

- `도구` › '원문 일괄 확보'(PDF 없는 문헌 전체) 또는 목록 다중 선택 후 우클릭 '원문 확보 (N건)'.
- 순차 진행 + 진행률·예상 남은 시간 표시, 완료 후 '확보/구독DB/미확보' 브리핑.

**Q. 학위논문 원문은?**

- 무료 기관 리포지터리 경로(RISS → dCollection)를 자동 추적해 첨부(프록시·로그인 불필요).
- 대학별 이용 동의·DRM 으로 막히면 브라우저로 상세를 열어 주고, 다운로드하면 폴더 감시로 자동 첨부.

**Q. 여러 건을 동시에 받으면 엉뚱한 논문에 붙지 않나요?**

- 전역 단일 감시가 **파일명과 제목(국문·영문)을 대조**해 유일 후보에만 자동 첨부.
- 애매하면 '이 PDF 는 어느 논문?' 확인 팝업이 추천 후보를 상단에 제시.

**Q. 앱은 못 찾았는데 도서관 검색으로 원문 URL 을 찾았어요.**

- 실패 팝업의 '원문 URL로 확보…' 에 그 주소(또는 도서관 프록시 주소)를 붙여넣기 → 브라우저로 열림 → 받으면 자동 첨부.
- 코리아스콜라 등 KCI·RISS 에 안 잡히는 DB 에 유용합니다.

**Q. 첨부한 PDF 를 앱 안에서 보고 주석을 달 수 있나요?**

- 네 — 상세 패널의 첨부를 클릭하면 **앱 안 PDF 뷰어**(별도 창).
- 확대/축소 · 폭·쪽 맞춤 · 한쪽/두쪽 보기 · 페이지 이동 · 인쇄(주석 포함).
- 주석: 드래그 후 우클릭 또는 `H`(하이라이트)·`U`(밑줄)·`N`(메모), 색 선택 가능.
- 저장 위치: PDF 옆 `<파일명>.annots.json` 사이드카 → 라이브러리 동기화를 따라감.
- 사이드바 **'주석 검색'** 으로 라이브러리 전체 주석 검색.
- 주석·대화 패널의 글자는 **골라서 복사할 수 있습니다**(예전에는 막혀 있었습니다).
- PDF 가 아닌 첨부는 OS 기본 앱으로 열립니다.

**Q. 읽고 있는 논문에 대해 AI 에게 물어볼 수 있나요?**

- 네 — PDF 뷰어 툴바 **[대화]** → 오른쪽 도크가 **`주석`·`대화` 두 탭**으로 갈립니다(손잡이로 폭 조절).
- **지금 읽는 논문 한 편만**을 근거로 답하고, 이어서 되물을 수 있습니다. 문헌에서 확인되지 않는 것은 지어내지 말라고 시킵니다.
- 답변 속 **`(p.쪽)` 표기가 곧 버튼**이라 누르면 그 근거 자리로 갑니다. 쪽 번호는 모델이 적은 것을 믿지 않고 앱이 원문에서 되찾아 확정합니다.
- 답변이 **쓰이는 대로 흘러나옵니다**(Claude CLI·Antigravity CLI). [중지] 하면 받은 데까지 남습니다.
- 입력은 `Ctrl+Enter` 전송. AI 제공자 설정이 필요합니다.

**Q. 논문에 안 나오는 것도 물어볼 수 있나요?**

- 네(2026.8.11부터). 용어의 뜻, 그 방법의 통상적인 한계, 배경 같은 것은 논문 밖에 있습니다.
- 다만 **답이 어디서 왔는지 표시가 갈립니다** — 굵고 눌리는 **(p.9)** 는 앱이 **원문에서 실제로 찾아 확인한** 근거이고, **(일반 지식)** 은 논문 밖에서 온 것이라 쪽을 붙이지 않습니다.
- **(쪽 미확인)** 은 따옴표 친 인용인데 원문에서 못 찾았다는 뜻입니다 — 그대로 옮겨 적기 전에 눈으로 확인하세요.

**Q. 대화 내용이 다음에 열면 사라져 있어요.**

- ⚠ 정상입니다 — **대화는 그 창에서만 유지되고 저장되지 않습니다.** 남길 답만 **[보관]** 하세요.
- `새 대화` 는 이력만 버리고 **보관분은 남습니다.**
- 보관한 답변은 **'주석 검색' 에도 함께** 나옵니다(결과줄에 `주석 N · AI 대화 M`).
- 단, **주석 개수 배지와 인쇄 모음은 주석만** 셉니다.

**Q. PDF 안에서 낱말을 찾고 싶어요.**

- 뷰어에서 **`Ctrl+F`**. 열려 있는 PDF **전체**에서 찾습니다 — 아직 화면에 그려지지 않은 쪽도 포함합니다.
- **띄어쓰기·줄바꿈·대소문자를 무시**하므로 PDF 특유의 줄 끊김('교육
과정')에 걸리지 않습니다.
- `Enter`·`Shift+Enter` 로 다음·이전, `Esc` 로 닫습니다.

**Q. 연결이 끊긴 PDF 가 쌓였어요.**

- 첨부 '연결 해제' 는 파일을 지우지 않아 첨부 폴더에만 남습니다.
- 사이드바 *기타* › **'연결 안 된 PDF'** 에서 목록·파일명 필터·크기 정렬로 확인.
- 처리: **문헌에 연결** · **새 서지로 만들기** · **선택 삭제**(주석 사이드카·빈 폴더까지 정리).

## AI 기능

**Q. AI 를 쓰려면 따로 돈을 내야 하나요?**

- 앱 자체에 AI 요금은 **없습니다** — 사용자가 이미 가진 자원으로 동작.
- **구독 CLI형**(키 불필요): `Claude CLI (구독)` · `Antigravity CLI (Google 구독)` — 설치 + 최초 1회 로그인.
- **API형**(본인 키): `Anthropic API 키` · `OpenAI API 키` · `Gemini API 키`.
- ⚠ 목록에 보이는 `Codex CLI (향후 지원)` 는 **아직 고를 수 없습니다**(비활성).
- 실행하면 그 구독·키의 사용량이 소모됩니다.
- AI 를 설정하지 않아도 나머지 기능은 그대로 됩니다.

**Q. CLI 제공자는 어떻게 설치·로그인하나요?**

- ⚙설정 › AI 의 '설치' 버튼 → **1 설치 → 2 로그인 → 3 확인** 3단계 안내.
- 설치·로그인은 **별도 콘솔 창**에서 진행됩니다(설치 로그를 봐야 하고, 로그인은 브라우저 인증이 콘솔에서 끝나야 하므로).
- 각 벤더의 **공식 설치 방법**을 사용 — Claude Code 는 Node.js 없이 설치되는 네이티브 설치.
- 설치 후 **앱을 재시작할 필요가 없습니다**(Windows PATH 변경을 앱이 다시 확인).
- ⚠ Ibis 가 '항상 위 고정' 이면 콘솔 창이 뒤에 열릴 수 있습니다 — 작업표시줄을 확인하세요.

**Q. '본문 텍스트가 없어 요약을 건너뜁니다' 가 나와요.**

- 스캔본(이미지) PDF 이거나 텍스트 레이어에 워터마크만 반복되는 경우.
- OCR 처리된 PDF 로 교체하면 요약됩니다.

**Q. AI 요약이 논문 앞부분만 읽는 것 같아요.**

- 고쳤습니다 — 학위논문 46편 실측에서 읽은 분량이 평균 **59% → 99%** 로 올랐습니다.
- 100쪽 넘는 논문의 결론·논의도 읽습니다. 얼마나 읽었는지는 결과에 적힙니다.

**Q. AI 요약을 다시 돌리면 내 메모·태그가 지워지나요?**

- 아닙니다 — 노트는 `## AI 요약` 섹션만 교체하고 **앞의 사용자 메모는 보존**.
- 태그·키워드도 직전 AI 가 넣은 것만 교체하고 수동 입력분은 유지.

**Q. 서지정보 채우기는 항상 AI 를 쓰나요?**

- 아닙니다 — DOI 가 있으면 **Crossref·KCI 권위 소스를 먼저** 조회.
- 빈 항목이 남을 때만 첨부 PDF 표지를 AI 로 분석.
- DOI 만으로 다 채워지면 결과에 'AI 생략' 표시(사용량 절약).

**Q. PDF 없이도 서지정보를 채울 수 있나요?**

- DOI 가 있으면 PDF 없이 Crossref 로 채웁니다.
- DOI·PDF 가 **둘 다 없으면** 채울 수 없고 원문 확보를 먼저 안내합니다.
- 학위논문·단행본도 유형에 맞춰(수여기관·학위 / 출판사·출판지) 채워집니다.

**Q. AI 가 429(사용량 제한) 오류를 냅니다.**

- 사용량·속도 제한입니다. 잠시 후 재시도하거나 다른 제공자·모델로 변경.
- ⚙설정에서 **'폴백' 제공자**를 지정하면 1차 실패 시 자동 재시도합니다.

**Q. 모델 칸은 비워도 되나요?**

- 비우면 CLI형은 개인 기본값, API형은 내장 기본값(Anthropic `claude-haiku-4-5` · OpenAI `gpt-4o-mini` · Gemini `gemini-2.0-flash`).
- 모델명을 넣으면 호출마다 그 모델을 강제(haiku 계열은 빠르고 절약적).

**Q. 여러 문헌을 한 번에 요약·채우기 할 수 있나요?**

- 다중 선택 후 우클릭 › 'AI 요약 (N건)' · '서지정보 채우기 (N건)'.
- **일괄 요약도 동시에 돕니다 (2026.8.7)** — `⚙설정 › AI` 의 **[동시 실행]**(1~5, 기본 3)만큼 나란히 처리합니다. 종전에는 한 건씩 차례로 돌았습니다.
- ⚠ **올린다고 무조건 빨라지지 않습니다** — 구독(CLI)은 사용량 한도에 그만큼 빨리 닿고, API 키는 분당 한도에 걸립니다. 한도로 보이는 실패가 두 건 이상이면 브리핑이 낮춰 보라고 알려 줍니다.
- ⚠ 이 설정은 **AI 호출에만** 걸립니다 — 학술DB 검색·원문 확보의 동시 요청 수는 따라 올라가지 않습니다.
- 진행률·예상 남은 시간이 표시되고, 완료 후 건별 성공/실패·태그를 브리핑으로 확인.

**Q. 테마는 몇 가지인가요?**

- **16종** — 자체 제작 4종(Slate·Ivory·Bright·Graphite) + 다크 8종(Dark Modern·One Dark Pro·Dracula·Nord·Monokai·Tokyo Night·Solarized Dark·GitHub Dark) + 라이트 4종(Solarized Light·GitHub Light·Quiet Light·Ayu Light).

- ⚙설정 › 일반 › 표시 › 테마에서 선택 — 즉시 적용, 저장되어 재시작 후에도 유지.

**Q. 글꼴을 바꿀 수 있나요? 꼭 받아야 하나요?**

- 테마와 **별개 설정**입니다 — 테마가 어울리는 글꼴을 제안하고(종이톤 테마는 명조), 직접 고르면 테마를 바꿔도 유지됩니다.
- **고를 수 있는 글꼴** 4항목: `Pretendard (기본)` · `본명조` · `나눔고딕` · `고정폭(나눔고딕코딩·JetBrains Mono)`.
- **Pretendard 는 설치본에 이미 들어 있어** 받을 필요가 없습니다.
- **'글꼴 받기' 카탈로그**는 5종: 본명조(22.7MB) · 나눔고딕(2.0MB) · 나눔명조(2.9MB) · 나눔고딕코딩(2.2MB) · JetBrains Mono(0.1MB) — 전부 SIL OFL 1.1. **나눔명조는 카탈로그에만 있고 선택 목록에는 없습니다.**
- **시스템 글꼴**(설치돼 있을 때만): 맑은 고딕 · 함초롬돋움 · 함초롬바탕 — 라이선스상 파일을 포함하거나 대신 받아 줄 수 없습니다.
- 받지 않아도 화면은 정상입니다(설치된 글꼴로 자동 대체). 설치 파일 용량을 줄이려고 기본 포함하지 않습니다.

**Q. 왼쪽 레일 아이콘을 다시 누르면?**

- 그 패널이 **접히고/펴집니다** — 목록을 넓게 볼 때 사용(그래프 모드에서는 그래프 패널).

**Q. ScienceON 키를 지우려는데 칸을 비워도 안 지워져요.**

- 키 칸은 '빈 칸은 유지' 규칙입니다.
- 설정된 키 옆의 **'지움' 버튼 → 저장** 으로 삭제(ScienceON 이 검색 목록에서 사라짐).
- 환경변수로 넣은 키는 UI 에서 지워지지 않습니다.
- 이메일 칸은 예외 — 비우고 저장하면 삭제됩니다.
- KCI·국립중앙도서관은 입력 칸이 없어 지울 것도 없습니다. `secrets.json` 에 예전에 넣어 둔 `kci_api_key`·`nl_seoji_key` 는 **이제 쓰이지 않으니** 그대로 두어도 무해합니다.

**Q. '이메일(OA·polite)' 칸은 무슨 키인가요?**

- 발급 키가 아니라 **Unpaywall 조회 + Crossref/OpenAlex polite pool 등록용 이메일**.
- 필수는 아니지만 OA 자동 확보 품질을 위해 권장.

**Q. 도구에 있던 '라이브러리' 가 안 보여요.**

- **2026.8.7 에 `⚙설정 › 라이브러리` 탭으로 옮겨졌습니다** — 라이브러리 위치 변경·새로 만들기·열기·사본 저장(백업)·업데이트 확인이 거기 있습니다.
- 설정은 이제 **일반 · AI · 검색·원문 · 클라우드 · 라이브러리** 5개 탭입니다(레일 맨 아래 ⚙).

**Q. 검색 결과에 색칠이 됐는데 뭔가요?**

- 검색어에 해당하는 자리를 제목·저자·수록처에서 칠해, **왜 그 문헌이 걸렸는지** 바로 보이게 한 것입니다(2026.8.7).
- 세 칸 어디에도 검색어가 없으면 `일치: 초록·주제어` 처럼 **어디서 걸렸는지 밝힙니다**.
- **검색 결과 화면에서만** 칠합니다 — 컬렉션이나 전체 서지에서 지난 검색어가 칠해져 있으면 더 헷갈리기 때문입니다.

**Q. '항상 위 고정' 이 재시작하면 풀려요.**

- 정상 — 이 설정은 저장하지 않습니다. 필요할 때 다시 체크하세요.
- 본창에만 적용(설정·도구·그래프·상세·PDF 등 별도 창은 제외).

**Q. 별도 창에서 '닫기' 를 누르면 앱 전체가 꺼지나요?**

- 아니요 — 창 컨트롤은 **지금 조작 중인 창에만** 적용됩니다.
- 앱 전체를 끄려면 본창의 닫기 버튼.

**Q. 설정·PDF 같은 별도 창이 화면 밖이나 엉뚱한 모니터에 떠요.**

- 고쳤습니다 — 125·150% 배율에서 창 좌표에 배율이 두 번 곱해지던 문제였습니다.
- 최신 버전으로 업데이트하면 본창 옆에 제대로 뜹니다.

**Q. 업데이트했더니 컬럼 폭이 초기화됐어요.**

- 업데이트 시 WebView 캐시를 비우면서 사소한 로컬 상태가 초기화될 수 있습니다.
- 서지·PDF 등 실제 데이터에는 영향 없습니다.
- 헤더 경계를 다시 드래그하면 저장되고, 더블클릭하면 기본 폭으로 복원.

**Q. 앱을 영어로 쓸 수 있나요?**

- 현재 웹판 UI 는 **한국어 전용**입니다.
- 설정의 '언어' 항목은 참고문헌의 국문/영문 표기용이며 인터페이스 언어와 다릅니다.

**Q. 온보딩을 건너뛰었어요.**

- 모든 항목(라이브러리 위치·이메일·ScienceON·도서관 경유·AI)은 ⚙설정에서 언제든 변경 가능.
- 이미 데이터가 있으면 온보딩 창은 다시 뜨지 않습니다.

**Q. 버전·라이선스·저작권은 어디서 확인하나요?**

- `도움말 › Ibis 정보 · 라이선스` — 제품명·버전·저작권·배포 라이선스·실행 환경 + **제3자 구성요소 고지**.

- **Ibis 로 만든 서지 데이터와 문서는 전적으로 사용자의 것입니다.**
