# FAQ · 문제 해결

## 설치·실행

### "Windows에서 PC를 보호했습니다"(SmartScreen)가 떠요
배포판은 코드 서명이 없어 나타나는 표준 경고입니다.
**"추가 정보" → "실행"**을 누르면 됩니다. 파일은 이 저장소의 Releases에서 받은 것만 사용하세요.

### 백신이 파일을 격리했어요
PyInstaller 계열 실행 파일에서 드물게 오탐이 있습니다. 격리 해제 후 예외 등록하거나,
의심스러우면 Releases의 파일 해시와 대조하세요. 문제가 반복되면 Issues로 알려주세요.

### 실행해도 창이 안 떠요
- 작업 표시줄·트레이를 확인하세요.
- 그래도 없으면 작업 관리자에서 Ibis/python 프로세스를 종료 후 재실행,
  반복 시 Issues에 OS 버전과 함께 제보해 주세요.

### 처음 켜니 'Ibis 시작하기' 창이 떴어요
첫 실행 시 뜨는 선택적 온보딩 마법사입니다. 라이브러리 위치·KCI/ScienceON·이메일·AI를 한 번에 안내할 뿐
전부 [나중에]로 건너뛰어도 됩니다. 검색·인용 삽입·서지 관리는 아무 설정 없이 바로 되고,
건너뛴 항목은 ⚙설정·🔧도구에서 언제든 넣을 수 있습니다. 이미 데이터가 있는 기존 사용자에게는 다시 뜨지 않습니다.

## 한글 연동

### 문서에 연결이 안 돼요 / 인용이 비활성이에요
Ibis는 워드프로세서를 **대신 실행하지 않고 이미 열린 앱에만 붙습니다.** 한글/Word가 꺼져 있으면
**독립 모드**로 시작하고, 이 상태에서도 검색·서지 관리·스타일 설정은 다 되지만 문서에 인용을 꽂는 기능만 막힙니다.
먼저 한글이나 Word에서 작업할 문서를 연 다음 **우측 상단 모드 배지를 클릭**하세요.
한글·Word가 둘 다 켜져 있으면 '연결할 앱 선택' 메뉴가 뜨고, 연결되면 배지 옆에 문서명이 표시됩니다.
문서를 새로 열었다면 배지 메뉴의 '🔄 목록 새로고침'으로 갱신합니다.

### 한글 보안 모듈 팝업이 떠요
한글이 외부 프로그램의 문서 접근을 확인하는 정상 동작입니다.
Ibis는 등록을 자동 시도하므로 보통은 팝업 없이 동작하지만, 뜨면 **허용**을 선택하세요. 1회 허용 후에는 다시 묻지 않는 것이 보통입니다.

### 한글이 설치되어 있지 않아요
독립 모드로 실행됩니다(한글이 꺼져 있어도 Ibis가 한글을 대신 띄우지 않습니다).
검색·수집·정리·내보내기는 전부 가능하고, 인용 삽입만 한글/Word 연결이 필요합니다.

### "누름틀을 지울까요?" 같은 팝업이 떠요
참고문헌 재구축 중 뜨는 한글의 '누름틀 삭제' 확인 팝업은 앱이 자동 응답 후 원복하므로 사용자가 조작할 필요가 없습니다.
계속 손이 가야 한다면 버전을 확인하고 최신 릴리스로 업데이트하세요.

### 인용을 실수로 지웠어요 / 문서가 꼬였어요
**참고문헌 갱신**을 실행하세요 — 실제 문서에 남아 있는 인용 필드를 기준으로
기록과 참고문헌이 다시 맞춰집니다.

### 논문마다 다른 저널 스타일을 쓸 수 있나요?
네. 스타일은 **문서마다 따로 저장**됩니다. 사이드바 '문서 연동'의 문서를 우클릭 › '인용 스타일'에서 문서별로 지정하면,
그 문서의 본문 인용·참고문헌이 즉시 그 스타일로 다시 렌더되고 이후 인용도 그 스타일을 씁니다.
문서에 연결하지 않은 상태에서 바꾸면 앱 전체 기본 스타일만 바뀝니다.

## 검색·API 키

### KCI·ScienceON API 키는 어떻게 받나요?
국내 소스인 KCI·ScienceON만 인증키가 필요하고, 두 소스는 키가 설정돼 있을 때만 검색 소스 드롭다운에 나타납니다.
- **KCI**: [open.kci.go.kr](https://open.kci.go.kr) → 'KCI 데이터 제공 › OPEN API › OPEN API 키신청'에서 **단일 인증키**를 발급받아 ⚙설정 'KCI 인증키' 칸에 입력·저장.
- **ScienceON**: [scienceon.kisti.re.kr](https://scienceon.kisti.re.kr) 로그인 → '인증키 발급 신청' → **Client ID·인증키·등록 MAC 3개 값**을 각각 입력해야 활성화됩니다(하나라도 빠지면 안 됨).
- 키가 없어도 Crossref·OpenAlex·Semantic Scholar·arXiv는 바로 사용할 수 있습니다.

### 검색 결과가 이상하거나 비어 있어요
- DOI가 있으면 검색창에 DOI(또는 doi.org 링크)를 붙여넣는 것이 가장 정확합니다.
- 국문 논문은 KCI/ScienceON, 해외 논문은 Crossref/OpenAlex가 잘 맞습니다.
- ⚡멀티로 여러 DB를 한 번에 비교해 보세요(한 소스가 실패해도 나머지는 진행됩니다).

### 내 서지 검색은 어디까지 훑나요?
소스를 '내 서지'로 두면 제목·저자·수록처·태그·키워드·AI 요약(노트)·초록·영문 병기 필드까지 전문검색(FTS)합니다.
AI 요약 본문의 단어로도 문헌이 찾아집니다. 단, 검색어가 3자 미만이면 제목·수록처만 보는 단순 매칭으로 폴백합니다.

### 어떤 형식을 가져오고 내보낼 수 있나요?
- **가져오기(6형식)**: RIS·BibTeX·CSL·EndNote(.enw)·RefWorks·Tab. '＋추가' 창에 붙여넣거나 끌어놓으면 자동 인식됩니다.
- **내보내기(2형식)**: CSL-JSON(.json)·BibTeX(.bib)만 지원합니다.

## PDF·원문

### PDF 자동 확보가 계속 실패해요
- 무료 공개본(OA)이 없는 구독 DB 논문이 원인의 대부분입니다 → **도서관 경유로 열기** 사용
- ⚙설정에 **이메일**을 넣으면 Unpaywall이 활성화되어 확보율이 올라갑니다.
- 학위논문은 무료 리포지터리(RISS → dCollection) 경로를 앱이 자동으로 따라가 첨부합니다.

### 구독 DB 논문을 자동으로 내려받아 주지는 않나요?
하지 않습니다 — 의도된 설계입니다. 상당수 대학 도서관·DB 제공사가 **스크립트·AI 에이전트 등
자동화 도구를 통한 접속과 대량 다운로드를 이용약관으로 금지**하고 있고, 위반 시 개인 계정 정지나
**기관 전체 IP 차단** 같은 불이익이 발생할 수 있습니다. 그래서 Ibis는 인증 창을 열어 주는
단계까지만 자동화하고, 원문 열람·다운로드는 사용자가 직접 하도록 설계했습니다.
도서관 경유 기능은 소속 기관의 라이선스 정책을 확인한 뒤 본인 책임 하에 이용하세요.

### 도서관 교외접속(경유)은 어떻게 설정하나요?
⚙설정에 '도서관 경유 URL'(예: `https://proxy.○○.ac.kr/link?url=`)과 '도서관 홈페이지'를 입력하세요.
프록시는 미로그인 상태면 접근을 튕기므로, '도서관 홈페이지 로그인 열기'로 **먼저 한 번 로그인해 세션을 만든 뒤**
'도서관 경유로 열기'를 쓰세요. 받은 PDF는 다운로드 폴더 감시로 자동 첨부됩니다.
주소 형식은 도서관 홈페이지의 교외접속 안내에서 확인할 수 있습니다.

### 첨부한 PDF를 앱 안에서 바로 보고 주석을 달 수 있나요?
인앱 PDF 뷰어와 주석(하이라이트·밑줄·메모)은 **차기 0.6.0(예정)** 기능입니다.
현재 0.5.5에서는 상세 패널의 PDF 첨부를 클릭하면 외부 기본 앱으로 열립니다.

## AI

### AI 기능에 비용이 드나요?
Ibis 자체는 무료이고 AI 서버도 없습니다. **본인이 가진 자원**(Claude 구독 CLI,
Google Antigravity CLI, 또는 본인 API 키)을 연결해 쓰는 방식이라,
비용·쿼터는 각 제공자 계정을 따릅니다. AI를 설정하지 않아도 나머지 기능은 그대로 됩니다.

### Claude CLI / Antigravity CLI가 없다고 나와요
⚙설정 → AI에서 **설치** 버튼을 누르면 확인 후 자동 설치합니다(Claude CLI는 Node.js 필요).
설치 뒤 터미널에서 한 번 로그인(`claude` 또는 `agy` 실행)이 필요하고,
PATH 반영을 위해 Ibis 재시작이 필요할 수 있습니다.

### 요약 결과 태그가 마음에 안 들어요
- 그래프 뷰에서 태그 노드 **우클릭 → 이름 변경·병합/삭제**
- 🔧도구 → **AI 태그 정리**: 표기 변형 병합·번역쌍 병기·과잉 일반 태그 삭제를 일괄 제안(반영은 사용자가 선택)

### 스캔본 PDF는 요약이 안 돼요
텍스트 추출이 안 되는 이미지 스캔본은 '본문 텍스트가 없어 요약을 건너뜁니다'로 나옵니다(OCR 미탑재).
OCR 처리된 PDF로 교체하면 요약할 수 있습니다.

### AI 요약을 다시 돌리면 내가 쓴 메모·태그가 지워지나요?
아닙니다. 노트는 '## AI 요약' 섹션만 새로 교체하고 그 앞의 사용자 메모는 그대로 둡니다.
태그·키워드도 직전 AI가 넣었던 것만 갈아끼우고 수동 입력한 것은 보존합니다.

## 데이터

### 데이터가 외부로 전송되나요?
서지·첨부·설정은 모두 로컬에 저장됩니다. 외부 통신은 ① 학술 DB 검색 ② PDF 확보
③ 사용자가 설정한 AI 제공자 호출뿐이며, AI 호출 시 **해당 PDF 본문만** 그 제공자에게 전달됩니다.
API 키·AI 설정·테마는 항상 로컬 전용이라 클라우드로 동기화되지 않습니다.

### 여러 PC에서 같이 쓰려면?
라이브러리 폴더(🔧도구 → 라이브러리 → 폴더 열기)를 OneDrive 등 동기화 폴더에 두고,
다른 PC에서는 도구 › 라이브러리 › '열기'로 같은 폴더에 연결하세요.
컬렉션·태그·첨부 PDF·저널 스타일까지 함께 동기화됩니다. 문서는 고유 ID로 추적되므로 파일명이 달라져도 이어집니다.
단, API 키·AI 설정은 PC마다 로컬이라 따로 넣어야 하고, 두 PC에서 **동시에** 수정하는 것은 피하세요.

### 라이브러리를 백업하려면?
🔧도구 › 라이브러리 › **사본 저장(백업)**으로 현재 라이브러리(+첨부)를 다른 폴더로 복사하거나,
라이브러리 폴더 전체를 복사하는 것이 가장 확실합니다.
⚙설정 → 내보내기(CSL-JSON/BibTeX)로 서지만 따로 받아둘 수도 있습니다.

### 테마·항상 위 고정은 어디서 바꾸나요?
둘 다 ⚙설정에 있습니다. 테마(Slate·Ivory·Bright·Graphite)는 저장되어 다음 실행에도 유지됩니다(기본 Ivory).
반면 '항상 위 고정'은 **세션 한정**이라 앱을 다시 켜면 해제되며(필요할 때마다 다시 체크), 본창에만 적용됩니다.
