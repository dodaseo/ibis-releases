# FAQ · 문제 해결

## 설치·실행

### "Windows에서 PC를 보호했습니다"(SmartScreen)가 떠요
베타 배포판은 코드 서명이 없어 나타나는 표준 경고입니다.
**"추가 정보" → "실행"**을 누르면 됩니다. 파일은 이 저장소의 Releases에서 받은 것만 사용하세요.

### 백신이 파일을 격리했어요
PyInstaller 계열 실행 파일에서 드물게 오탐이 있습니다. 격리 해제 후 예외 등록하거나,
의심스러우면 Releases의 파일 해시와 대조하세요. 문제가 반복되면 Issues로 알려주세요.

### 실행해도 창이 안 떠요
- 작업 표시줄·트레이를 확인하세요.
- 그래도 없으면 작업 관리자에서 Ibis/python 프로세스를 종료 후 재실행,
  반복 시 Issues에 OS 버전과 함께 제보해 주세요.

## 한글 연동

### 한글 보안 모듈 팝업이 떠요
한글이 외부 프로그램의 문서 접근을 확인하는 정상 동작입니다.
Ibis는 등록을 자동 시도하지만, 팝업이 뜨면 **허용**을 선택하세요. 1회 허용 후에는 다시 묻지 않는 것이 보통입니다.

### 한글이 설치되어 있지 않아요
독립 모드로 실행됩니다 ✦(0.4.0부터는 한글이 꺼져 있어도 한글을 새로 띄우지 않습니다).
검색·수집·정리·내보내기는 전부 가능하고, 인용 삽입만 한글/Word 연결이 필요합니다.

### "누름틀을 지울까요?" 같은 팝업이 떠요
구버전에서 참고문헌 갱신 중 나타나던 문제로, 현재 버전에서는 수정되었습니다.
계속 나타나면 버전을 확인하고 최신 릴리스로 업데이트하세요.

### 인용을 실수로 지웠어요 / 문서가 꼬였어요
**참고문헌 갱신**을 실행하세요 — 실제 문서에 남아 있는 인용 필드를 기준으로
기록과 참고문헌이 다시 맞춰집니다.

## 검색·API 키

### KCI·ScienceON API 키는 어떻게 받나요?
- **KCI**: [KCI OpenAPI](https://www.kci.go.kr)에서 키를 신청해 ⚙설정 → API 키에 입력
- **ScienceON**: [ScienceON OpenAPI](https://scienceon.kisti.re.kr)에서 클라이언트 ID·키 발급
- 키가 없어도 Crossref·OpenAlex·Semantic Scholar·arXiv는 바로 사용 가능합니다.

### 검색 결과가 이상하거나 비어 있어요
- DOI가 있으면 DOI로 검색하는 것이 가장 정확합니다.
- 국문 논문은 KCI/ScienceON, 해외 논문은 Crossref/OpenAlex가 잘 맞습니다.
- ⚡멀티 소스로 한 번에 여러 DB를 비교해 보세요.

## PDF·원문

### PDF 자동 확보가 계속 실패해요
- 무료 공개본(OA)이 없는 구독 DB 논문이 원인의 대부분입니다 → **도서관 경유로 열기** 사용
- ⚙설정에 **이메일**을 넣으면 Unpaywall이 활성화되어 확보율이 올라갑니다.

### 도서관 프록시는 어떻게 설정하나요?
소속 도서관의 교외접속 주소(예: `https://proxy.univ.ac.kr/link?url=`)를
⚙설정 → 프록시에 입력하세요. 이후 "도서관 경유로 열기"가 그 주소를 통해 원문을 엽니다.
주소 형식은 도서관 홈페이지의 교외접속 안내에서 확인할 수 있습니다.

## AI ✦

### AI 기능에 비용이 드나요?
Ibis 자체는 무료이고 AI 서버도 없습니다. **본인이 가진 자원**(Claude 구독 CLI,
Google Antigravity CLI, 또는 본인 API 키)을 연결해 쓰는 방식이라,
비용·쿼터는 각 제공자 계정을 따릅니다.

### Claude CLI / Antigravity CLI가 없다고 나와요
⚙설정 → AI에서 **설치** 버튼을 누르면 확인 후 자동 설치합니다.
설치 뒤 터미널에서 한 번 로그인(`claude` 또는 `agy` 실행)이 필요하고,
PATH 반영을 위해 Ibis 재시작이 필요할 수 있습니다.

### 요약 결과 태그가 마음에 안 들어요
- 그래프 뷰에서 태그 노드 **우클릭 → 이름 변경·병합/삭제**
- ⚙설정 → 도구 → **🧹 AI 태그 정리**: 표기 변형 병합·번역쌍 병기·과잉 일반 태그 삭제를 일괄 제안

### 스캔본 PDF는 요약이 안 돼요
텍스트 추출이 안 되는 이미지 스캔본은 현재 지원하지 않습니다(OCR 미탑재).

## 데이터

### 데이터가 외부로 전송되나요?
서지·첨부·설정은 모두 로컬에 저장됩니다. 외부 통신은 ① 학술 DB 검색 ② PDF 확보
③ 사용자가 설정한 AI 제공자 호출뿐이며, AI 호출 시 해당 PDF 본문이 그 제공자에게 전달됩니다.

### 여러 PC에서 같이 쓰려면?
라이브러리 폴더(⚙설정 → 도구 → 라이브러리 폴더 열기)를 OneDrive 등 동기화 폴더에 두세요.
문서는 UUID로 추적되므로 파일명이 달라져도 이어집니다. 단, 두 PC에서 **동시에** 수정하는 것은 피하세요.

### 라이브러리를 백업하려면?
라이브러리 폴더 전체 복사가 가장 확실하고, ⚙설정 → 내보내기(CSL-JSON/BibTeX)로
서지만 따로 받아둘 수도 있습니다.
